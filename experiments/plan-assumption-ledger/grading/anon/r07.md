# RSI Reflect + Self-Compact Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish deploying the already-built `session-reflect` ("rsi reflect") system, then add **self-compact**: inside a ralph-loop-armed autonomous run, when context fill crosses ~70% (30% of a 1M window remaining), Claude autonomously writes `tasks/mission.md`, clears context, and resumes from the file — no user prompt required.

**Architecture:** Four pieces. (1) `scripts/idle-handoff.sh` (built, unwired) gets a systemd user timer, mirroring the existing `claude-cl-sync` unit pair. (2) The context-fill detector already living in `context-baggage.py` is extracted into a shared `context_fill.py` module. (3) A new PreToolUse hook, `context-self-compact.py`, uses that module to watch fill % — but only inside directories where `.claude/ralph-loop.local.md` is armed (the same isolation boundary `orchestrate`'s Phase 0 already established) — and when threshold crosses, synchronously invokes `session-reflect`'s existing `reflect.sh mission` mode, then emits a hook decision telling Claude to hand off and self-clear. (4) `orchestrate/hooks/compact-reinject.sh` (already re-injects doctrine after `/clear`) gains a "freshly self-compacted" branch that tells Claude to resume immediately, without waiting on the user.

**Tech Stack:** bash, Python 3 (stdlib only), Claude Code hooks (PreToolUse, SessionStart), `jq`, systemd user units, the already-installed `session-reflect` skill and `ralph-loop@claude-plugins-official` plugin.

**Spec:** No standalone spec doc exists for this feature; the brainstorming happened inline during plan-writing by reading the existing `session-reflect`, `context-baggage.py`, `orchestrate`, and `ralph-loop` implementations directly (see Context section below in place of a spec citation).

## Context discovered during design (read this before Task 1)

- **`session-reflect` ("rsi reflect") is already fully built and wired.** `skills/session-reflect/reflect.sh` + `lib.sh` handle `precompact` / `sessionend` / `subagentstop` / `mission` modes; all three hook events are already registered in `settings.json`. Its `mission` mode already writes `tasks/mission.md` (schema: Done/Next/Blocked/Open questions) and is already triggered synchronously on a session's 2nd `PreCompact` (see `reflect.sh:834-864`, the "2nd-compact defence"). **Do not rebuild any of this** — self-compact calls into it.
- **`scripts/idle-handoff.sh` is the one built-but-undeployed piece of rsi-reflect.** It's a systemd-timer-shaped script (idle-session mission.md preemption) but no `.service`/`.timer` unit exists anywhere in the repo. Task 1 closes this gap.
- **`context-baggage.py`** already computes context fill % correctly against a 1M window (model-prefix detection + `[1m]` marker + observed-usage fallback) and already uses **threshold 0.70** — this is empirically tuned (raised from 0.25 on 2026-08-08 after measuring a 95.5% cache-hit ratio) and matches the "30% of 1m context" the user specified almost exactly. Self-compact reuses this exact threshold and detector rather than inventing a new one.
- **`orchestrate/hooks/compact-reinject.sh`** (SessionStart, matcher `startup|compact|clear`) already re-injects ralph-loop doctrine + a `tasks/mission.md` pointer after any compact/clear. It does not currently distinguish "this /clear was a scheduled self-compact handoff" from "the user manually typed /clear for an unrelated reason" — Task 5 adds that distinction via `tasks/mission.md`'s own mtime (cheap, file-based, doesn't depend on session_id continuity across `/clear`, which is unconfirmed).
- **`ralph-loop`'s Stop hook** (`~/.claude/plugins/cache/claude-plugins-official/ralph-loop/1.0.0/hooks/stop-hook.sh`) blocks session exit and re-feeds the *same* prompt text — it does **not** reset context, and does not obviously refire `UserPromptSubmit` for its synthetic re-feed. Self-compact therefore does **not** hook `UserPromptSubmit` or `Stop` (uncertain firing semantics, and Stop-hook `decision:block` composition across two independently-registered Stop hooks is undocumented — risking a conflict with ralph-loop's own block). Instead it hooks `PreToolUse` (matcher `*`), which fires reliably on every tool call regardless of how the loop iterates — already proven safe to add in this exact repo (`aggregator-transcript-guard.py`, `git-push-merge-check.sh` both do this).

## Assumptions

1. **The model can invoke the CLI's `/clear` via the `SlashCommand` tool, and this actually resets context (not just accepts the text).** Evidence for the tool existing: `SlashCommand` appears in two independent Claude-Code tool enumerations in this repo (`continue-nudge-classifier.py:357`, `skills/ab-testing-prompt-changes/ab_harness.py:63`), alongside `Agent`/`Skill`/`Task`. Evidence is indirect — nobody in this repo has exercised it to invoke a *built-in* slash command autonomously. **This is why Task 2 is a gating spike, not a leap of faith.** If the spike fails, `SELF_COMPACT_FORCE_CLEAR=0` degrades the feature to "autonomous mission.md write + a strongly-worded handoff recommendation," which is still a real improvement over today's ask-first nudge and ships regardless of the spike's outcome.
2. **`PreToolUse` hook output supports a non-blocking `additionalContext` field** (same envelope shape `UserPromptSubmit` already uses in `context-baggage.py`), letting a hook inject text without denying/asking on the tool call. Task 2 confirms the exact JSON shape empirically; Task 4's code is written against the most-likely shape (bare `additionalContext`, no `permissionDecision`) with a one-line patch point flagged if the spike finds otherwise.
3. **After `/clear`, Claude Code does not auto-generate a new turn from a bare SessionStart hook output** — some subsequent user (or ralph-loop re-feed) input is still required to make the assistant actually act. Self-compact's "picks up autonomously" claim is therefore precise for ralph-loop-armed sessions (where the loop's own Stop hook or a supervising process reliably supplies that next turn) and not a claim about turning an idle interactive REPL into a fully unattended agent. This matches the scope boundary in Global Constraints — no code changes needed to correct for this, just accurate documentation in Task 7.

```python
#!/usr/bin/env python3
"""Shared context-window fill-percentage detection for Claude Code hooks.

Extracted from context-baggage.py so context-baggage.py (interactive
ask-first nudge) and context-self-compact.py (autonomous handoff, ralph-loop
armed sessions only) share one empirically-tuned detector instead of drifting
apart. Threshold policy stays local to each caller; this module only answers
"how full is the window right now."
"""
from __future__ import annotations

import json
import os

BASE_MAX = 200_000
ONE_M = 1_000_000

# Claude Code model IDs that run at 1M context by default. Prefixes, so
# dated variants (claude-opus-4-1-20250805) match too.
ONE_M_MODEL_PREFIXES = (
    "claude-opus-4-",
    "claude-sonnet-4-",
    "claude-opus-5",
    "claude-sonnet-5",
)

# Explicit 1M marker in the model ID, e.g. `claude-opus-5[1m]`. Checked
# before the prefix list so it keeps working across model generations
# without another edit here.
ONE_M_MARKER = "[1m]"


def detect_max_tokens(model: str | None, observed_max: int) -> int:
    override = os.environ.get("CLAUDE_CONTEXT_MAX")
    if override:
        try:
            return int(override)
        except ValueError:
            pass
    if model:
        if ONE_M_MARKER in model.lower():
            return ONE_M
        if any(model.startswith(p) for p in ONE_M_MODEL_PREFIXES):
            return ONE_M
    if observed_max > BASE_MAX:
        return ONE_M
    return BASE_MAX


def _read_last_usage(transcript_path: str) -> tuple[dict | None, str | None, int]:
    """Single pass over a transcript JSONL. Returns (last_usage, last_model, observed_max)."""
    last_usage: dict | None = None
    last_model: str | None = None
    observed_max = 0
    with open(transcript_path, "r", errors="replace") as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
            try:
                obj = json.loads(line)
            except json.JSONDecodeError:
                continue
            if obj.get("type") != "assistant":
                continue
            msg = obj.get("message", {})
            model = msg.get("model")
            if model and model != "<synthetic>":
                last_model = model
            usage = msg.get("usage")
            if usage:
                last_usage = usage
                total = (
                    usage.get("input_tokens", 0)
                    + usage.get("cache_creation_input_tokens", 0)
                    + usage.get("cache_read_input_tokens", 0)
                )
                if total > observed_max:
                    observed_max = total
    return last_usage, last_model, observed_max


def fill_pct(transcript_path: str) -> tuple[float, int, str | None]:
    """Returns (fill_fraction, max_tokens, last_model).

    fill_fraction is 0.0 if the transcript is missing, unreadable, or has no
    assistant usage records yet (fresh session).
    """
    if not transcript_path or not os.path.exists(transcript_path):
        return 0.0, BASE_MAX, None
    last_usage, last_model, observed_max = _read_last_usage(transcript_path)
    max_tokens = detect_max_tokens(last_model, observed_max)
    if not last_usage:
        return 0.0, max_tokens, last_model
    total_tokens = (
        last_usage.get("input_tokens", 0)
        + last_usage.get("cache_creation_input_tokens", 0)
        + last_usage.get("cache_read_input_tokens", 0)
    )
    return total_tokens / max_tokens, max_tokens, last_model
```

#!/usr/bin/env python3
"""PreToolUse hook: autonomous context self-compact for ralph-loop-armed
sessions.

Scope: fires ONLY when `.claude/ralph-loop.local.md` is present in the
session's cwd (orchestrate's Phase 0 arming) — the same isolation boundary
the orchestrate skill already documents. Plain interactive sessions are
untouched; they keep context-baggage.py's ask-first nudge.

When fill % crosses THRESHOLD (matches context-baggage.py's empirically
tuned 0.70), this hook:
  1. Debounces to avoid re-reading the transcript on every tool call.
  2. Skips if a mission.md handoff was already written recently (cooldown —
     avoids re-triggering every tool call while a handoff is in flight).
  3. Synchronously invokes `reflect.sh mission` (existing session-reflect
     infra — same call idle-handoff.sh already makes) to freshen
     tasks/mission.md while the prompt cache is still warm.
  4. On success, emits a non-blocking hookSpecificOutput telling Claude to
     hand off in one line and self-clear via the SlashCommand tool (or, if
     SELF_COMPACT_FORCE_CLEAR=0, to strongly recommend a fresh session
     instead of forcing one).

Fails open on every path — a bug here must never block a tool call.
"""
from __future__ import annotations

import json
import os
import subprocess
import sys
import time

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import context_fill  # noqa: E402

THRESHOLD = float(os.environ.get("SELF_COMPACT_THRESHOLD", "0.70"))
CHECK_EVERY_N_CALLS = int(os.environ.get("SELF_COMPACT_CHECK_EVERY_N_CALLS", "15"))
COOLDOWN_SECONDS = int(os.environ.get("SELF_COMPACT_COOLDOWN_SECONDS", "1800"))
DISABLE_FLAG = os.environ.get("SELF_COMPACT_DISABLE_FLAG", os.path.expanduser("~/.claude/self-compact.disable"))
# Default set per docs/superpowers/plans/2026-08-17-self-compact-spike-results.md
# — flip to "0" there if the SlashCommand /clear spike failed.
FORCE_CLEAR = os.environ.get("SELF_COMPACT_FORCE_CLEAR", "1") not in ("0", "false", "False", "")
REFLECT_ROOT = os.environ.get("REFLECT_ROOT", os.path.expanduser("~/.claude/reflections"))
REFLECT_SH = os.environ.get("REFLECT_SH_OVERRIDE", os.path.expanduser("~/.claude/skills/session-reflect/reflect.sh"))
COUNT_DIR = os.path.join(REFLECT_ROOT, "self-compact-counts")


def ralph_loop_armed(cwd: str) -> bool:
    return os.path.isfile(os.path.join(cwd, ".claude", "ralph-loop.local.md"))


def should_check(count_dir: str, session_id: str, every_n: int) -> bool:
    """Increments a per-session counter; returns True every `every_n`th call.
    Best-effort — a corrupt/missing counter file just resets to 0, never crashes.
    """
    os.makedirs(count_dir, exist_ok=True)
    path = os.path.join(count_dir, session_id)
    try:
        with open(path, "r") as f:
            n = int(f.read().strip() or "0")
    except (FileNotFoundError, ValueError):
        n = 0
    n += 1
    try:
        with open(path, "w") as f:
            f.write(str(n))
    except OSError:
        pass
    return n % every_n == 0


def in_cooldown(mission_path: str, cooldown_seconds: int) -> bool:
    if not os.path.isfile(mission_path):
        return False
    age = time.time() - os.path.getmtime(mission_path)
    return 0 <= age < cooldown_seconds


def decide(fill: float, threshold: float, disable_flag: str | None) -> str | None:
    if disable_flag and os.path.isfile(disable_flag):
        return None
    if fill < threshold:
        return None
    return "trigger"


def build_handoff_message(pct_display: int, force_clear: bool) -> str:
    base = (
        f"[self-compact] Context is {pct_display}% full inside an armed ralph-loop run. "
        "tasks/mission.md has just been freshly written (self-compact policy — this "
        "is not a stopping point, it's a scheduled handoff)."
    )
    if force_clear:
        return (
            base
            + " Say ONE line noting the handoff (e.g. \"Self-compacting at "
            f"{pct_display}% — resuming from tasks/mission.md.\"), then invoke the "
            "SlashCommand tool with `/clear` in this same turn. Do not ask the user "
            "for permission — this is an autonomous, scheduled context reset within "
            "an already-armed autonomous run. After the clear, re-read tasks/mission.md "
            "and tasks/session-constraints.md and continue from the Next section "
            "immediately."
        )
    return (
        base
        + " SELF_COMPACT_FORCE_CLEAR is disabled in this environment, so do not clear "
        "automatically. Instead say plainly that context is near the self-compact "
        "threshold and tasks/mission.md is fresh and ready, and recommend running "
        "`/clear` now before continuing."
    )


def run_reflect_mission(payload_json: str, cwd: str) -> bool:
    """Synchronous call into session-reflect's existing mission mode. Returns
    True iff reflect.sh mission completed successfully (per its own exit code
    — reflect.sh always exits 0 by design, so success here means "ran without
    a Python-level exception," not "mission.md content is guaranteed good.").
    """
    env = dict(os.environ)
    env.pop("MODE", None)  # mirrors idle-handoff.sh's `env -u MODE` idiom
    env["REFLECT_ROOT"] = REFLECT_ROOT
    try:
        result = subprocess.run(
            ["bash", REFLECT_SH, "mission"],
            input=payload_json,
            capture_output=True,
            text=True,
            timeout=90,
            cwd=cwd,
            env=env,
        )
        return result.returncode == 0
    except (subprocess.TimeoutExpired, OSError):
        return False


def main() -> int:
    try:
        payload = json.load(sys.stdin)
    except (json.JSONDecodeError, ValueError):
        return 0

    session_id = payload.get("session_id") or ""
    transcript_path = payload.get("transcript_path") or ""
    cwd = payload.get("cwd") or ""

    if not session_id or not cwd or not os.path.isdir(cwd):
        return 0
    if not ralph_loop_armed(cwd):
        return 0
    if not should_check(COUNT_DIR, session_id, CHECK_EVERY_N_CALLS):
        return 0

    mission_path = os.path.join(cwd, "tasks", "mission.md")
    if in_cooldown(mission_path, COOLDOWN_SECONDS):
        return 0

    fill, _, _ = context_fill.fill_pct(transcript_path)
    if decide(fill, THRESHOLD, DISABLE_FLAG) is None:
        return 0

    payload_json = json.dumps(payload)
    if not run_reflect_mission(payload_json, cwd):
        # mission.md write failed/timed out — do NOT force a handoff without
        # a fresh mission.md behind it. Fail open silently; the next
        # debounced check will retry.
        return 0

    pct_display = int(fill * 100)
    message = build_handoff_message(pct_display, FORCE_CLEAR)
    # Shape confirmed in docs/superpowers/plans/2026-08-17-self-compact-spike-results.md.
    print(json.dumps({"hookSpecificOutput": {"hookEventName": "PreToolUse", "additionalContext": message}}))
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

# test_self_compact_e2e.sh — end-to-end: armed ralph-loop dir, high-fill
# transcript, PreToolUse call -> mission.md written + handoff JSON emitted.
# Uses the stub claude binary from skills/session-reflect/tests (offline,
# zero API cost).
set -euo pipefail

WORKTREE="$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")/.." && pwd)"
STUBS_DIR="$WORKTREE/tests/stubs"

fail() { echo "FAIL: $*" >&2; exit 1; }
info() { echo "  -> $*"; }

STUB_SCRATCH="$(mktemp -d -t self-compact-e2e-stub-XXXXXX)"
cp "$STUBS_DIR/claude" "$STUB_SCRATCH/claude" 2>/dev/null || cat > "$STUB_SCRATCH/claude" <<'STUB'
#!/usr/bin/env bash
cat >/dev/null || true
cat <<'JSON'
{"type":"result","result":"# Mission\n\n## Done\n- stub\n\n## Next\n- stub next\n\n## Blocked\n(none)\n\n## Open questions\n(none)\n","usage":{}}
JSON
STUB
chmod +x "$STUB_SCRATCH/claude"
export PATH="$STUB_SCRATCH:$PATH"

REFLECT_ROOT="$(mktemp -d -t self-compact-e2e-root-XXXXXX)"
export REFLECT_ROOT
export SELF_COMPACT_CHECK_EVERY_N_CALLS=1   # fire on the first call, no debounce wait
export SELF_COMPACT_THRESHOLD=0.70
export SELF_COMPACT_DISABLE_FLAG=/nonexistent/never-exists

SCRATCH_CWD="$(mktemp -d -t self-compact-e2e-cwd-XXXXXX)"
mkdir -p "$SCRATCH_CWD/.claude"
cat > "$SCRATCH_CWD/.claude/ralph-loop.local.md" <<'EOF'
---
active: true
iteration: 1
session_id:
max_iterations: 25
completion_promise: "x"
started_at: "2026-08-17T00:00:00Z"
---
body
EOF

TRANSCRIPT="$REFLECT_ROOT/high-fill-transcript.jsonl"
cat > "$TRANSCRIPT" <<'JSONL'
{"type":"user","message":{"role":"user","content":"go"}}
{"type":"assistant","message":{"role":"assistant","model":"claude-opus-5","usage":{"input_tokens":100,"cache_creation_input_tokens":0,"cache_read_input_tokens":899900}}}
JSONL

SID="e2e-sid-1"
PAYLOAD=$(jq -cn --arg sid "$SID" --arg tp "$TRANSCRIPT" --arg cwd "$SCRATCH_CWD" \
  '{session_id:$sid, transcript_path:$tp, cwd:$cwd, tool_name:"Read", tool_input:{}}')

echo "TEST: armed + high fill -> mission.md written + handoff JSON emitted"
OUT=$(echo "$PAYLOAD" | python3 "$WORKTREE/context-self-compact.py")

echo "$OUT" | jq -e '.hookSpecificOutput.additionalContext' >/dev/null \
  || fail "no additionalContext in hook output: $OUT"
echo "$OUT" | grep -qi 'self-compact' || fail "handoff message missing self-compact framing"

[[ -f "$SCRATCH_CWD/tasks/mission.md" ]] || fail "tasks/mission.md was not written"
grep -q 'stub next' "$SCRATCH_CWD/tasks/mission.md" || fail "mission.md content is not from the stub"
info "mission.md written + handoff JSON emitted"

echo "TEST: second call within cooldown -> no output (already handed off)"
OUT2=$(echo "$PAYLOAD" | python3 "$WORKTREE/context-self-compact.py")
[[ -z "$OUT2" ]] || fail "expected no output on cooldown re-check, got: $OUT2"
info "cooldown suppressed re-trigger"

echo "TEST: unarmed directory -> no output regardless of fill"
UNARMED_CWD="$(mktemp -d -t self-compact-e2e-unarmed-XXXXXX)"
UNARMED_PAYLOAD=$(jq -cn --arg sid "e2e-sid-2" --arg tp "$TRANSCRIPT" --arg cwd "$UNARMED_CWD" \
  '{session_id:$sid, transcript_path:$tp, cwd:$cwd, tool_name:"Read", tool_input:{}}')
OUT3=$(echo "$UNARMED_PAYLOAD" | python3 "$WORKTREE/context-self-compact.py")
[[ -z "$OUT3" ]] || fail "expected no output in unarmed dir, got: $OUT3"
[[ ! -f "$UNARMED_CWD/tasks/mission.md" ]] || fail "mission.md should not exist in unarmed dir"
info "unarmed directory correctly ignored"

echo "TEST: disable flag suppresses trigger even when armed + high fill"
DISABLE_FLAG="$(mktemp -t self-compact-e2e-disable-XXXXXX)"
DISABLED_CWD="$(mktemp -d -t self-compact-e2e-disabled-XXXXXX)"
mkdir -p "$DISABLED_CWD/.claude"
cp "$SCRATCH_CWD/.claude/ralph-loop.local.md" "$DISABLED_CWD/.claude/"
DISABLED_PAYLOAD=$(jq -cn --arg sid "e2e-sid-3" --arg tp "$TRANSCRIPT" --arg cwd "$DISABLED_CWD" \
  '{session_id:$sid, transcript_path:$tp, cwd:$cwd, tool_name:"Read", tool_input:{}}')
OUT4=$(echo "$DISABLED_PAYLOAD" | SELF_COMPACT_DISABLE_FLAG="$DISABLE_FLAG" python3 "$WORKTREE/context-self-compact.py")
[[ -z "$OUT4" ]] || fail "expected no output with disable flag set, got: $OUT4"
info "disable flag suppressed trigger"

rm -rf "$STUB_SCRATCH" "$REFLECT_ROOT" "$SCRATCH_CWD" "$UNARMED_CWD" "$DISABLED_CWD" "$DISABLE_FLAG" 2>/dev/null || true
echo "OK: self-compact e2e tests passed"
exit 0
```
