# RSI Reflect + Self-Compact Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the loop between `session-reflect`'s reflection artifacts and the two systems positioned to consume them: (1) **RSI Reflect** — rewire the recursive-self-improvement daily reviewer to read cheap, structured `session-reflect` artifacts instead of raw multi-MB transcripts; (2) **Self-Compact** — an opt-in, per-project mechanism that autonomously writes `tasks/mission.md` when context crosses a fill threshold (~70% full / 30% remaining of a 1M window) and makes the post-reset continuation autonomous instead of interactive, for projects that have opted in (ralph-loop-armed worktrees, or an explicit marker file).

**Architecture:**

*RSI Reflect* — pure prompt-surface change. `recursive-self-improvement/config/prompt.md` Step 2 switches its primary source from `~/.claude/projects/*/*.jsonl` (full transcript reads) to `~/.claude/reflections/sessions/*/final.json` (session-reflect's already-distilled `patterns/discoveries/turning_points/digressions/obstacles_to_autonomy` schema), with cheap head/tail timestamp extraction for wellbeing timing signals and a per-session fallback to raw-transcript reading only when no reflection artifact exists for that session. No new code — `session-reflect` already produces the artifacts; this plan only points the existing reader at them.

*Self-Compact* — extends two files that already do 90% of this job. `context-baggage.py` (already computes context fill % on every `UserPromptSubmit` and nudges at 70%) gets a new opt-in branch: when the project has self-compact enabled (marker file, or a `.claude/ralph-loop.local.md` already present), instead of asking the user, it backgrounds a `reflect.sh mission` call (same mode `idle-handoff.sh` already drives), writes a small state file recording the arm event, and tells Claude to keep working. `skills/orchestrate/hooks/compact-reinject.sh` (already re-injects doctrine on `SessionStart(startup|compact|clear)` when a mission.md exists) gets a new branch that reads that state file and turns the existing soft "re-read it" reminder into an assertive "continue without asking" instruction. The actual context reset is Claude Code's own built-in automatic compaction — no new process-supervision or slash-command invocation is attempted; self-compact's contribution is making that reset happen on a fresh, high-quality mission.md well before the forced auto-compact, and making the resume silent.

**Tech Stack:** bash (`skills/session-reflect/reflect.sh`, `skills/orchestrate/hooks/compact-reinject.sh`), Python 3 stdlib only (`context-baggage.py`, new `context_fill.py`), `jq`/`awk`/`date` (already required by session-reflect), Claude Code hooks (`UserPromptSubmit`, `SessionStart(startup|compact|clear)`).

**Spec / prior art consulted:** `skills/session-reflect/README.md` (artifact schema — explicitly names "a separate later system that reads these artifacts" as future work, which this plan is), `docs/superpowers/plans/2026-08-02-sigil-gated-autonomous-orchestration.md` (state-file security pattern this plan reuses for `self-compact.local.md`), `recursive-self-improvement/config/prompt.md` + `categories.md` + `config.json` (current daily-review agent), `recursive-self-improvement/proposals/2026-08-02-repeat-compact-in-session.md` (the proposal this plan resolves).

```python
#!/usr/bin/env python3
"""Shared context-fill detection, factored out of context-baggage.py so
self-compact (context-baggage.py's arm branch) and any future consumer
don't each re-derive max-context and fill-percentage logic.

Context window detection (in priority order):
    1. CLAUDE_CONTEXT_MAX env var (explicit override, in tokens)
    2. Model ID prefix — Opus/Sonnet 4.x run with 1M in this setup
    3. Observed usage — if any assistant turn has exceeded 200k tokens,
       the session is 1M, regardless of model name
    4. Default 200k
"""
import json
import os

BASE_MAX = 200_000
ONE_M = 1_000_000

# Claude Code model IDs that run at 1M context by default. Prefixes, so
# dated variants (claude-opus-4-1-20250805) match too.
ONE_M_MODEL_PREFIXES = (
    "claude-opus-4-",
    "claude-sonnet-4-",
    "claude-opus-5",
    "claude-sonnet-5",
)

# Explicit 1M marker in the model ID, e.g. `claude-opus-5[1m]`. Checked
# before the prefix list so it keeps working across model generations
# without another edit here.
ONE_M_MARKER = "[1m]"


def detect_max_tokens(model, observed_max):
    override = os.environ.get("CLAUDE_CONTEXT_MAX")
    if override:
        try:
            return int(override)
        except ValueError:
            pass
    if model:
        if ONE_M_MARKER in model.lower():
            return ONE_M
        if any(model.startswith(p) for p in ONE_M_MODEL_PREFIXES):
            return ONE_M
    if observed_max > BASE_MAX:
        return ONE_M
    return BASE_MAX


def read_transcript_usage(transcript_path):
    """Single pass over a transcript JSONL. Returns
    (user_msg_count, last_usage, last_model, observed_max, file_size, last_cwd).
    last_cwd is the most recent non-empty `cwd` field seen on any record —
    Claude Code embeds it per-turn, and this is the cheapest way to recover
    a project's cwd from inside a hook whose own payload may omit it."""
    file_size = os.path.getsize(transcript_path)
    user_msg_count = 0
    last_usage = None
    last_model = None
    observed_max = 0
    last_cwd = None
    with open(transcript_path, "r", errors="replace") as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
            try:
                obj = json.loads(line)
            except json.JSONDecodeError:
                continue

            cwd = obj.get("cwd")
            if cwd:
                last_cwd = cwd

            obj_type = obj.get("type")
            if obj_type == "user":
                user_msg_count += 1
            elif obj_type == "assistant":
                msg = obj.get("message", {})
                model = msg.get("model")
                if model and model != "<synthetic>":
                    last_model = model
                usage = msg.get("usage")
                if usage:
                    last_usage = usage
                    total = (
                        usage.get("input_tokens", 0)
                        + usage.get("cache_creation_input_tokens", 0)
                        + usage.get("cache_read_input_tokens", 0)
                    )
                    if total > observed_max:
                        observed_max = total
    return user_msg_count, last_usage, last_model, observed_max, file_size, last_cwd


def fill_pct(transcript_path):
    """Returns (pct, user_msg_count, max_tokens, last_cwd)."""
    user_msg_count, last_usage, last_model, observed_max, file_size, last_cwd = (
        read_transcript_usage(transcript_path)
    )
    max_tokens = detect_max_tokens(last_model, observed_max)
    if last_usage:
        total_tokens = (
            last_usage.get("input_tokens", 0)
            + last_usage.get("cache_creation_input_tokens", 0)
            + last_usage.get("cache_read_input_tokens", 0)
        )
        pct = total_tokens / max_tokens
    else:
        pct = file_size / (max_tokens * 4)
    return pct, user_msg_count, max_tokens, last_cwd
```

```python
#!/usr/bin/env python3
"""
UserPromptSubmit hook: warns when context is over THRESHOLD with potentially
stale/off-topic content. Fires every MESSAGE_INTERVAL user messages once
threshold is met.

For projects that have opted into self-compact (see context_fill import
and the ARM branch below), the same threshold instead autonomously writes
tasks/mission.md and tells Claude to keep working rather than asking.

Context window / fill-percentage detection lives in context_fill.py.
"""
import json
import os
import sys

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
from context_fill import fill_pct

# Raised from 0.25 -> 0.70 on 2026-08-08 after measuring 95.5% cache-hit
# ratio across 7 days / $3,073 spend (probes/analyze_sessions.py). At that
# hit ratio, holding baggage is cheap and resetting is expensive
# (cache_write ~$5-10 per cold event). Nudge should fire when handoff to
# a fresh session starts to pay off, not on any drift.
THRESHOLD = 0.70
MESSAGE_INTERVAL = 5


def main():
    try:
        data = json.load(sys.stdin)
    except Exception:
        sys.exit(0)

    transcript_path = data.get("transcript_path", "")
    if not transcript_path or not os.path.exists(transcript_path):
        sys.exit(0)

    pct, user_msg_count, max_tokens, last_cwd = fill_pct(transcript_path)

    if user_msg_count == 0 or user_msg_count % MESSAGE_INTERVAL != 0:
        sys.exit(0)

    if pct < THRESHOLD:
        sys.exit(0)

    pct_display = int(pct * 100)
    message = (
        f"Context is {pct_display}% full ({user_msg_count} messages in this session; "
        f"window: {max_tokens // 1000}k tokens). "
        "At this fill, a fresh-session handoff via tasks/mission.md is usually cheaper "
        "than an in-place /compact: --fork-session on a warm cache measured ~77% hit "
        "(session-reflect empirical), while /compact invalidates the prefix and forces "
        "cache_write on subsequent turns. "
        "Suggest to the user: (a) write tasks/mission.md (done / next / blocked / open "
        "questions), (b) start a fresh session in the same cwd and load it, OR (c) "
        "continue here and accept the drift. Ask which."
    )
    print(json.dumps({"hookSpecificOutput": {"hookEventName": "UserPromptSubmit", "additionalContext": message}}))


if __name__ == "__main__":
    main()
```

#!/usr/bin/env bash
# SessionStart(startup|compact|clear) hook: re-inject session-lifecycle
# doctrine depending on what's armed in this project dir. Doctrine decays
# after compaction — this hook is the re-injection channel.
#
# Precedence (independent checks, most-constraining first):
#   1. ralph-loop.local.md  -> existing autonomy-contract doctrine (unchanged)
#   2. self-compact.local.md -> "continue without asking" doctrine (new)
#   3. tasks/mission.md alone -> generic "re-read it" reminder (unchanged,
#      only fires when neither of the above armed state exists)
#
# Design constraints (advisor-reviewed, and reused unchanged for self-compact):
# - NEVER print the literal ralph sigil (parroting footgun).
# - State-file values are DATA: every field is regex-validated before
#   heredoc interpolation so a corrupted file cannot execute via $(…).
set -euo pipefail

STATE=".claude/ralph-loop.local.md"
SELFCOMPACT=".claude/self-compact.local.md"
MISSION="tasks/mission.md"

if [[ ! -f "$STATE" && ! -f "$SELFCOMPACT" && ! -f "$MISSION" ]]; then
  exit 0
fi

if [[ -f "$STATE" ]]; then
  ITER=$(awk '/^iteration:/{sub(/^iteration: */,""); print; exit}' "$STATE")
  [[ "$ITER" =~ ^[0-9]+$ ]] || ITER="?"

  AGE_NOTE=""
  STARTED=$(awk '/^started_at:/{sub(/^started_at: */,""); gsub(/"/,""); print; exit}' "$STATE")
  START_EPOCH=$(date -d "${STARTED:-invalid}" +%s 2>/dev/null || echo 0)
  if [[ "$START_EPOCH" -gt 0 ]] && (( $(date +%s) - START_EPOCH > 172800 )); then
    AGE_NOTE=$'\n- WARNING: this loop was armed over 48h ago. If the mission is dead, cancel it: rm .claude/ralph-loop.local.md (or /cancel-ralph). A stale armed loop blocks EVERY session that stops in this directory.'
  fi

  cat <<EOF
[autonomous-orchestration] Ralph loop ACTIVE (iteration ${ITER}). Context was just compacted, cleared, or restarted — re-arm the doctrine:
- Re-read tasks/mission.md, tasks/progress.md, and tasks/session-constraints.md NOW. Constraints are the first thing compaction kills — the file is authoritative. Trust files and git log over any memory of this conversation.
- You are the orchestrator: dispatch subagents for all reads/edits/tests; hold no code context yourself.
- Bias to action. Never end a turn with only a plan, a summary, or a question that mission.md or the dangerous-ops manifest already answers.
- Stop ONLY via the completion sigil recorded in tasks/mission.md, emitted ONLY when literally TRUE: verifier freshly green AND fresh-context reviewer confirmed. Never emit a false sigil. If no sigil is configured, the loop ends only at max-iterations.${AGE_NOTE}
EOF
fi

if [[ -f "$SELFCOMPACT" ]]; then
  ARMED_AT=$(awk '/^armed_at:/{sub(/^armed_at: */,""); gsub(/"/,""); print; exit}' "$SELFCOMPACT")
  ARMED_EPOCH=$(date -d "${ARMED_AT:-invalid}" +%s 2>/dev/null || echo 0)

  FILLPCT=$(awk '/^fill_pct_at_arm:/{sub(/^fill_pct_at_arm: */,""); print; exit}' "$SELFCOMPACT")
  [[ "$FILLPCT" =~ ^[0-9]+$ ]] || FILLPCT="?"

  SC_AGE_NOTE=""
  if [[ "$ARMED_EPOCH" -gt 0 ]] && (( $(date +%s) - ARMED_EPOCH > 21600 )); then
    SC_AGE_NOTE=$'\n- WARNING: this self-compact mission was armed over 6h ago. If the project has moved on, remove it: rm .claude/self-compact.local.md.'
  fi

  ARMED_DISPLAY="$ARMED_AT"
  [[ -n "$ARMED_DISPLAY" ]] || ARMED_DISPLAY="unknown time"

  cat <<EOF
[self-compact] Mission armed autonomously at ${ARMED_DISPLAY} (context was ${FILLPCT}% full). Context was just compacted, cleared, or restarted:
- Re-read tasks/mission.md and tasks/session-constraints.md NOW. Trust files over any memory of the pre-compact conversation.
- Continue the mission directly. Do not stop to ask the user whether to proceed — mission.md already answers that.
- Exception: if tasks/mission.md's Open Questions section is non-empty and blocks the very next action, ask only about that.${SC_AGE_NOTE}
EOF
fi

if [[ ! -f "$STATE" && ! -f "$SELFCOMPACT" && -f "$MISSION" ]]; then
  cat <<EOF
[context-lifecycle] tasks/mission.md exists in this project. Context was just compacted, cleared, or restarted — re-read it now, plus tasks/session-constraints.md if present. Do not rely on your memory of the pre-compact conversation for state that lives on disk.
EOF
fi
