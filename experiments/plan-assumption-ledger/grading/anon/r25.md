# RSI Reflect + Self-Compact Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship two feature packages: (1) **self-compact** — an opt-in, per-project autonomous hook that writes a fresh `tasks/mission.md` and directs Claude to run `/compact` once context crosses ~30% of the window, instead of waiting for the existing 70%-fill ask-based nudge; (2) **rsi reflect** — wires the recursive-self-improvement daily-review pipeline to consume session-reflect's structured reflection artifacts (`patterns`, `discoveries`, `turning_points`, `digressions`, `obstacles_to_autonomy`) instead of raw transcript greps, closing the loop session-reflect's own README calls out as a deferred "later system."

**Architecture:** Both packages are thin additions on top of already-shipped infrastructure — no new services, no new external dependencies. Self-compact reuses `skills/session-reflect/reflect.sh mission` mode (already writes `tasks/mission.md` via a cheap Haiku call) and the existing `SessionStart(compact)` re-injection hook (`skills/orchestrate/hooks/compact-reinject.sh`, already re-reads `tasks/mission.md` after any compact/clear) — it only adds the *trigger* at an earlier, autonomous point. RSI reflect adds a pure bash+jq digest script that the RSI daily-review prompt calls instead of reading raw `.jsonl` transcripts directly. The two packages reinforce each other: self-compact firing more often produces more `PreCompact` checkpoint artifacts, which is exactly the richer signal RSI reflect's `obstacles_to_autonomy` mining benefits from.

**Tech Stack:** Bash (GNU, Linux-only — matches `skills/session-reflect/reflect.sh`'s existing constraint), `jq`, Python 3 stdlib only (`unittest`), no new dependencies.

**Spec:** No separate spec doc exists for this work — brainstorming happened inline in this planning session against the live repo. This plan is self-contained; there is no earlier design doc to cross-reference.

## Global Constraints

- Linux + GNU coreutils + `jq` required, matching `skills/session-reflect/reflect.sh`'s existing constraint — no macOS/BSD portability shims.
- Python hook scripts: stdlib only, `unittest` for tests, no `pytest` (matches `permission-ledger/tests/`).
- All new hook scripts must be fast no-ops when not applicable (unarmed project, missing transcript, etc.) — never block or error into the user's turn.
- Every new UserPromptSubmit hook entry in `settings.json` follows the existing CLI-only guard: `[ "${CLAUDE_CODE_ENTRYPOINT:-cli}" = "cli" ] || exit 0; ...`.
- No change to `recursive-self-improvement/config/config.json`'s `components.daily_review` (stays `false`) — enabling the nightly agent is a separate cost/risk decision for the user, not part of this plan.
- No change to `context-baggage.py`'s external behavior (message text, 70% threshold, 5-message interval) — Task 1 is a pure refactor, verified by parity tests.

## Assumptions

- **`/compact` (in-session reset), not a fresh-session process respawn.** The user's phrasing ("resets + picks up autonomously") could mean either. Nothing in this repo can spawn and hand off to a brand-new `claude` process without a human or an external supervisor (ralph-loop-style) driving it — a hook can only inject text into the *current* turn. `/compact` is the one reset mechanism a hook can actually trigger (Claude runs the slash command itself when instructed). The existing `context-baggage.py` nudge at 70% argues fresh-session is cheaper on cache economics (`/compact` invalidates the cached prefix, forcing a `cache_write`); self-compact's mitigation is firing much earlier (30%, while there's still headroom) rather than trying to replicate the fresh-session mechanism. This tradeoff is documented in `skills/self-compact/SKILL.md` (Task 4) so the user can see the reasoning and reject it if they'd rather wait for a real fresh-session automation.
- **Autonomous pickup after compact needs no new code.** `skills/orchestrate/hooks/compact-reinject.sh` already fires on `SessionStart(startup|compact|clear)` and, for ANY project with `tasks/mission.md` present (not just ralph-loop-armed ones), injects a re-read reminder. Self-compact's mission.md write is picked up by this existing mechanism for free.
- **Self-compact is opt-in per project, default OFF.** Unattended `/compact` injection is a real behavior change (blast radius: compacting a user's context without asking). Mirrors the existing `.claude/ralph-loop.local.md` arm/disarm philosophy rather than being always-on.
- **"rsi reflect" = wire reflection artifacts into the *existing* daily-review prompt**, not build a new review pipeline. `recursive-self-improvement/config/prompt.md` Step 2 currently reads raw `.jsonl` transcripts directly; this plan only changes what that step reads from, not the review logic around it.

```python
"""Shared context-fill-percentage calculator for context-baggage.py and
skills/self-compact/hook.py. Pure functions, no side effects beyond the
read of `transcript_path`.

Context window detection (in priority order):
    1. context_max_override param (explicit override, in tokens)
    2. Model ID prefix — Opus/Sonnet 4.x+ run with 1M in this setup
    3. Observed usage — if any assistant turn has exceeded 200k tokens,
       the session is 1M, regardless of model name
    4. Default 200k
"""
import json
import os

BASE_MAX = 200_000
ONE_M = 1_000_000

# Claude Code model IDs that run at 1M context by default. Prefixes, so
# dated variants (claude-opus-4-1-20250805) match too.
ONE_M_MODEL_PREFIXES = (
    "claude-opus-4-",
    "claude-sonnet-4-",
    "claude-opus-5",
    "claude-sonnet-5",
)

# Explicit 1M marker in the model ID, e.g. `claude-opus-5[1m]`. Checked
# before the prefix list so it keeps working across model generations
# without another edit here.
ONE_M_MARKER = "[1m]"


def detect_max_tokens(model, observed_max, context_max_override=None):
    if context_max_override:
        try:
            return int(context_max_override)
        except ValueError:
            pass
    if model:
        if ONE_M_MARKER in model.lower():
            return ONE_M
        if any(model.startswith(p) for p in ONE_M_MODEL_PREFIXES):
            return ONE_M
    if observed_max > BASE_MAX:
        return ONE_M
    return BASE_MAX


def read_transcript_usage(transcript_path):
    """Returns (user_msg_count, last_usage, last_model, observed_max, file_size)."""
    file_size = os.path.getsize(transcript_path)
    user_msg_count = 0
    last_usage = None
    last_model = None
    observed_max = 0

    with open(transcript_path, "r", errors="replace") as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
            try:
                obj = json.loads(line)
            except json.JSONDecodeError:
                continue

            obj_type = obj.get("type")
            if obj_type == "user":
                user_msg_count += 1
            elif obj_type == "assistant":
                msg = obj.get("message", {})
                model = msg.get("model")
                if model and model != "<synthetic>":
                    last_model = model
                usage = msg.get("usage")
                if usage:
                    last_usage = usage
                    total = (
                        usage.get("input_tokens", 0)
                        + usage.get("cache_creation_input_tokens", 0)
                        + usage.get("cache_read_input_tokens", 0)
                    )
                    if total > observed_max:
                        observed_max = total

    return user_msg_count, last_usage, last_model, observed_max, file_size


def compute_fill_pct(transcript_path, context_max_override=None):
    """Returns (fill_pct, max_tokens, user_msg_count), or None if
    transcript_path is missing/nonexistent."""
    if not transcript_path or not os.path.exists(transcript_path):
        return None
    user_msg_count, last_usage, last_model, observed_max, file_size = read_transcript_usage(
        transcript_path
    )
    max_tokens = detect_max_tokens(last_model, observed_max, context_max_override)
    if last_usage:
        total_tokens = (
            last_usage.get("input_tokens", 0)
            + last_usage.get("cache_creation_input_tokens", 0)
            + last_usage.get("cache_read_input_tokens", 0)
        )
        fill_pct = total_tokens / max_tokens
    else:
        fill_pct = file_size / (max_tokens * 4)
    return fill_pct, max_tokens, user_msg_count
```

```python
#!/usr/bin/env python3
"""
UserPromptSubmit hook: warns when context is over THRESHOLD with potentially
stale/off-topic content. Fires every MESSAGE_INTERVAL user messages once
threshold is met.

Fill-percentage detection lives in context_fill.py (shared with
skills/self-compact/hook.py, which uses the same calculation at a lower,
autonomous-trigger threshold — see that skill for the counterpart to this
ask-based nudge).
"""
import json
import os
import sys

_HERE = os.path.dirname(os.path.abspath(__file__))
if _HERE not in sys.path:
    sys.path.insert(0, _HERE)

import context_fill  # noqa: E402

# Raised from 0.25 -> 0.70 on 2026-08-08 after measuring 95.5% cache-hit
# ratio across 7 days / $3,073 spend (probes/analyze_sessions.py). At that
# hit ratio, holding baggage is cheap and resetting is expensive
# (cache_write ~$5-10 per cold event). Nudge should fire when handoff to
# a fresh session starts to pay off, not on any drift.
THRESHOLD = 0.70
MESSAGE_INTERVAL = 5


def main():
    try:
        data = json.load(sys.stdin)
    except Exception:
        sys.exit(0)

    transcript_path = data.get("transcript_path", "")
    context_max_override = os.environ.get("CLAUDE_CONTEXT_MAX")
    result = context_fill.compute_fill_pct(transcript_path, context_max_override)
    if result is None:
        sys.exit(0)
    fill_pct, max_tokens, user_msg_count = result

    if user_msg_count == 0 or user_msg_count % MESSAGE_INTERVAL != 0:
        sys.exit(0)

    if fill_pct < THRESHOLD:
        sys.exit(0)

    pct_display = int(fill_pct * 100)
    message = (
        f"Context is {pct_display}% full ({user_msg_count} messages in this session; "
        f"window: {max_tokens // 1000}k tokens). "
        "At this fill, a fresh-session handoff via tasks/mission.md is usually cheaper "
        "than an in-place /compact: --fork-session on a warm cache measured ~77% hit "
        "(session-reflect empirical), while /compact invalidates the prefix and forces "
        "cache_write on subsequent turns. "
        "Suggest to the user: (a) write tasks/mission.md (done / next / blocked / open "
        "questions), (b) start a fresh session in the same cwd and load it, OR (c) "
        "continue here and accept the drift. Ask which."
    )
    print(json.dumps({"hookSpecificOutput": {"hookEventName": "UserPromptSubmit", "additionalContext": message}}))


if __name__ == "__main__":
    main()
```

```python
#!/usr/bin/env python3
"""
UserPromptSubmit hook: when self-compact is armed for this project
(.claude/self-compact.local.md present) and context fill crosses the armed
threshold, ensures tasks/mission.md is fresh and instructs Claude to run
/compact now, autonomously — no user prompt.

Opt-in only. Absent the state file, this hook is a fast no-op.

State file format (.claude/self-compact.local.md, CWD-relative, key: value
lines — mirrors .claude/ralph-loop.local.md):
    threshold: 0.30
    armed_at: 2026-08-17T10:00:00Z
    last_triggered_at: 2026-08-17T10:32:00Z   (blank until first trigger)

Env:
    SELF_COMPACT_COOLDOWN_SECONDS         (default: 600) - minimum gap
        between successive /compact directives, so the same
        threshold-crossing state doesn't re-fire on every prompt while a
        /compact is pending.
    SELF_COMPACT_MISSION_MAX_AGE_SECONDS  (default: 300) - skip a fresh
        reflect.sh mission call if tasks/mission.md is already this new.
    SELF_COMPACT_REFLECT_SH  (default: $HOME/.claude/skills/session-reflect/reflect.sh)
    SELF_COMPACT_REFLECT_TIMEOUT          (default: 90) - wall-clock budget
        for the synchronous reflect.sh mission subprocess call (mission
        mode's own internal budget is 60s; this adds headroom).
"""
import json
import os
import subprocess
import sys
from datetime import datetime, timezone

_HERE = os.path.dirname(os.path.abspath(__file__))
_REPO_ROOT = os.path.dirname(os.path.dirname(_HERE))
if _REPO_ROOT not in sys.path:
    sys.path.insert(0, _REPO_ROOT)

import context_fill  # noqa: E402

STATE_REL_PATH = os.path.join(".claude", "self-compact.local.md")
DEFAULT_THRESHOLD = 0.30


def parse_state(path):
    """Parses `key: value` lines. Returns dict; missing file -> None."""
    if not os.path.isfile(path):
        return None
    state = {}
    with open(path, "r") as f:
        for line in f:
            line = line.rstrip("\n")
            if ":" not in line:
                continue
            key, _, value = line.partition(":")
            state[key.strip()] = value.strip()
    return state


def write_state(path, state):
    tmp = path + ".tmp"
    with open(tmp, "w") as f:
        for key in ("threshold", "armed_at", "last_triggered_at"):
            f.write(f"{key}: {state.get(key, '')}\n")
    os.replace(tmp, path)


def now_iso():
    return datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")


def ensure_mission_fresh(cwd, session_id, transcript_path, hook_event_name):
    mission_path = os.path.join(cwd, "tasks", "mission.md")
    max_age = int(os.environ.get("SELF_COMPACT_MISSION_MAX_AGE_SECONDS", "300"))
    if os.path.isfile(mission_path):
        age = datetime.now().timestamp() - os.path.getmtime(mission_path)
        if age < max_age:
            return True  # already fresh — skip the reflect.sh call entirely

    reflect_sh = os.environ.get(
        "SELF_COMPACT_REFLECT_SH",
        os.path.expanduser("~/.claude/skills/session-reflect/reflect.sh"),
    )
    if not os.path.isfile(reflect_sh):
        return False
    payload = json.dumps(
        {
            "session_id": session_id,
            "transcript_path": transcript_path,
            "hook_event_name": hook_event_name,
            "cwd": cwd,
        }
    )
    timeout = int(os.environ.get("SELF_COMPACT_REFLECT_TIMEOUT", "90"))
    # MODE="" mirrors reflect.sh's own `env -u MODE` gotcha documented at
    # its 2nd-compact-defense call site: bash's ${MODE:-$ARG1} treats an
    # inherited empty MODE the same as unset, so this guards against a
    # stray MODE leaking in from this process's own environment.
    env = dict(os.environ)
    env["MODE"] = ""
    try:
        result = subprocess.run(
            ["bash", reflect_sh, "mission"],
            input=payload,
            capture_output=True,
            text=True,
            timeout=timeout,
            env=env,
        )
    except subprocess.TimeoutExpired:
        return False
    return result.returncode == 0 and os.path.isfile(mission_path)


def main():
    try:
        data = json.load(sys.stdin)
    except Exception:
        sys.exit(0)

    cwd = data.get("cwd") or os.getcwd()
    session_id = data.get("session_id", "")
    transcript_path = data.get("transcript_path", "")
    hook_event_name = data.get("hook_event_name", "UserPromptSubmit")

    state_path = os.path.join(cwd, STATE_REL_PATH)
    state = parse_state(state_path)
    if state is None:
        sys.exit(0)  # not armed — fast no-op

    try:
        threshold = float(state.get("threshold") or DEFAULT_THRESHOLD)
    except ValueError:
        threshold = DEFAULT_THRESHOLD

    cooldown = int(os.environ.get("SELF_COMPACT_COOLDOWN_SECONDS", "600"))
    last_triggered = state.get("last_triggered_at") or ""
    if last_triggered:
        try:
            last_dt = datetime.strptime(last_triggered, "%Y-%m-%dT%H:%M:%SZ").replace(
                tzinfo=timezone.utc
            )
            elapsed = datetime.now(timezone.utc).timestamp() - last_dt.timestamp()
            if elapsed < cooldown:
                sys.exit(0)  # still cooling down
        except ValueError:
            pass  # corrupt timestamp — do not block, fall through and re-trigger

    result = context_fill.compute_fill_pct(transcript_path)
    if result is None:
        sys.exit(0)
    fill_pct, max_tokens, _user_msg_count = result

    if fill_pct < threshold:
        sys.exit(0)

    mission_ok = ensure_mission_fresh(cwd, session_id, transcript_path, hook_event_name)

    state["last_triggered_at"] = now_iso()
    write_state(state_path, state)

    pct_display = int(fill_pct * 100)
    mission_note = (
        "tasks/mission.md is fresh."
        if mission_ok
        else "tasks/mission.md refresh failed or reflect.sh is unavailable — write it "
        "yourself before compacting (done / next / blocked / open questions)."
    )
    message = (
        f"[self-compact] Context is {pct_display}% full (armed threshold: "
        f"{int(threshold * 100)}% of {max_tokens // 1000}k tokens). "
        f"{mission_note} This project has self-compact armed "
        "(.claude/self-compact.local.md) — pre-authorized to reset now. "
        "Run /compact this turn, without asking. After compaction, "
        "re-read tasks/mission.md and continue from Next."
    )
    print(
        json.dumps(
            {
                "hookSpecificOutput": {
                    "hookEventName": "UserPromptSubmit",
                    "additionalContext": message,
                }
            }
        )
    )


if __name__ == "__main__":
    main()
```

---
name: self-compact
description: Use when a session should autonomously reset its own context via /compact once fill crosses a threshold (default 30% of the window), instead of waiting for the user to notice or for the existing 70%-fill ask-nudge. Opt-in per project; arm with skills/self-compact/enable.sh.

# self-compact

Autonomous early-and-often context reset. Once armed for a project,
every `UserPromptSubmit` checks context fill; crossing the threshold
writes a fresh `tasks/mission.md` (via session-reflect's `mission` mode)
and instructs Claude to run `/compact` immediately, without asking.
`SessionStart(compact)` already re-reads `tasks/mission.md` and re-injects
doctrine (`skills/orchestrate/hooks/compact-reinject.sh`), so pickup after
the reset is autonomous too — no separate wiring needed here.

## Why 30%, and why /compact and not a fresh session

`context-baggage.py`'s existing 70%-fill nudge recommends a **fresh
session** over `/compact`, because `--resume --fork-session` on a warm
cache measured ~77% cache-hit while `/compact` invalidates the cached
prefix and forces a `cache_write` on the next turn (session-reflect
README, verified 2026-08-08). That argument still holds — `/compact` is
not free. self-compact trades that for a mechanism a hook can actually
trigger: nothing in this repo can spawn and hand off to a brand-new
`claude` process without a human or an external supervisor (e.g. a
ralph-loop) driving it. Firing early (30%, not 70%) is the mitigation:
the `/compact` happens while there's still plenty of headroom rather
than at the edge, and the mission.md write means the handoff is durable
either way.

If you want the fresh-session behavior fully automated too, that needs
an external process supervisor (see the `ralph-loop` plugin) — out of
scope here.

## Arm / disarm

```bash
cd /path/to/project   # must be a repo/worktree root (has .git)
~/.claude/skills/self-compact/enable.sh        # threshold 0.30
~/.claude/skills/self-compact/enable.sh 0.25   # custom threshold
~/.claude/skills/self-compact/disable.sh       # or: rm .claude/self-compact.local.md
```

State lives in `.claude/self-compact.local.md` (CWD-scoped — same
convention as `.claude/ralph-loop.local.md`). Fields: `threshold`,
`armed_at`, `last_triggered_at` (cooldown bookkeeping, default 600s
between triggers — override via `SELF_COMPACT_COOLDOWN_SECONDS`).

## Failure modes

- Not armed (no state file): hook is a no-op, one `os.path.isfile` check.
- `reflect.sh mission` fails or times out: the injected message tells
  Claude to write `tasks/mission.md` itself before compacting rather
  than silently compacting without a handoff artifact.
- Corrupt `last_triggered_at`: treated as no-cooldown (fires again),
  never as a crash.

```bash
#!/usr/bin/env bash
# collect-reflections.sh — digest session-reflect artifacts for the RSI
# daily-review agent.
#
# Scans $REFLECT_ROOT/sessions/*/{final.json,checkpoints/*.json,subagents/*/final.json}
# for entries newer than the window, ranks most-recent first, and prints a
# byte-budgeted plain-text digest to stdout. Pure bash + jq, no `claude`
# calls, no network — safe to run standalone or invoked from the RSI
# daily-review prompt via Bash.
#
# Usage: collect-reflections.sh
#
# Env:
#   REFLECT_ROOT              (default: $HOME/.claude/reflections)
#   RSI_REFLECT_WINDOW_HOURS  (default: 24)
#   RSI_REFLECT_BYTE_BUDGET   (default: 24576)
#   RSI_REFLECT_PER_ENTRY_CAP (default: RSI_REFLECT_BYTE_BUDGET / 4)
set -euo pipefail

: "${REFLECT_ROOT:=$HOME/.claude/reflections}"
: "${RSI_REFLECT_WINDOW_HOURS:=24}"
: "${RSI_REFLECT_BYTE_BUDGET:=24576}"
: "${RSI_REFLECT_PER_ENTRY_CAP:=$((RSI_REFLECT_BYTE_BUDGET / 4))}"

SESSIONS_DIR="$REFLECT_ROOT/sessions"

if [[ ! -d "$SESSIONS_DIR" ]]; then
  echo "(no reflection artifacts found at $SESSIONS_DIR — fall back to raw transcripts)"
  exit 0
fi

window_min=$(( RSI_REFLECT_WINDOW_HOURS * 60 ))

# Candidate artifacts within the window: final.json (parent + subagent) and
# checkpoints/*.json, excluding the _malformed bucket.
mapfile -t candidates < <(
  find "$SESSIONS_DIR" \
    \( -path "$SESSIONS_DIR/_malformed" -o -path "$SESSIONS_DIR/_malformed/*" \) -prune -o \
    -type f -mmin "-${window_min}" \
    \( -name 'final.json' -o -path '*/checkpoints/*.json' \) -print \
    2>/dev/null | sort
)

if (( ${#candidates[@]} == 0 )); then
  echo "(no reflection artifacts in the last ${RSI_REFLECT_WINDOW_HOURS}h — fall back to raw transcripts)"
  exit 0
fi

# Dedupe per session dir: final.json always wins over a checkpoint.
declare -A chosen
for f in "${candidates[@]}"; do
  case "$f" in
    */checkpoints/*.json)
      sdir="$(dirname -- "$(dirname -- "$f")")"
      ;;
    */final.json)
      sdir="$(dirname -- "$f")"
      ;;
    *)
      continue
      ;;
  esac
  if [[ "$f" == */final.json ]]; then
    chosen["$sdir"]="$f"
  elif [[ -z "${chosen[$sdir]:-}" ]]; then
    chosen["$sdir"]="$f"
  fi
done

# Rank by generated_at field inside the JSON (fallback to file mtime), newest first.
entries=()
for sdir in "${!chosen[@]}"; do
  f="${chosen[$sdir]}"
  gen_at="$(jq -r '.generated_at // empty' "$f" 2>/dev/null || true)"
  if [[ -n "$gen_at" ]]; then
    epoch="$(date -d "$gen_at" +%s 2>/dev/null || echo 0)"
  else
    epoch="$(stat -c '%Y' "$f" 2>/dev/null || echo 0)"
  fi
  entries+=( "${epoch}"$'\t'"${f}" )
done

mapfile -t sorted < <(printf '%s\n' "${entries[@]}" | sort -t $'\t' -k1,1 -rn)
total_count=${#sorted[@]}

read_capped() {
  local path="$1"
  local body
  body="$(cat "$path" 2>/dev/null || true)"
  local body_bytes="${#body}"
  if (( body_bytes > RSI_REFLECT_PER_ENTRY_CAP )); then
    printf '[truncated at %d of %d bytes]\n' "$RSI_REFLECT_PER_ENTRY_CAP" "$body_bytes"
    printf '%s' "${body:0:$RSI_REFLECT_PER_ENTRY_CAP}"
  else
    printf '%s' "$body"
  fi
}

used=0
kept=0
digest=""

for line in "${sorted[@]}"; do
  f="${line#*$'\t'}"
  session_id="$(jq -r '.session_id // "unknown"' "$f" 2>/dev/null || echo unknown)"
  mode="$(jq -r '.mode // "unknown"' "$f" 2>/dev/null || echo unknown)"
  gen_at="$(jq -r '.generated_at // "unknown"' "$f" 2>/dev/null || echo unknown)"
  src="$(jq -r '.source_transcript // "unknown"' "$f" 2>/dev/null || echo unknown)"
  obstacles_count="$(jq -r '(.obstacles_to_autonomy // []) | length' "$f" 2>/dev/null || echo 0)"

  # read_capped is invoked for its byte-budget side effect on body size
  # accounting but the digest itself is built from jq fields below (not
  # the raw body) so the model sees structured, not-doubly-nested text.
  read_capped "$f" >/dev/null

  patterns="$(jq -r '(.patterns // []) | map("- " + .) | join("\n")' "$f" 2>/dev/null || true)"
  discoveries="$(jq -r '(.discoveries // []) | map("- " + .) | join("\n")' "$f" 2>/dev/null || true)"
  turning_points="$(jq -r '(.turning_points // []) | map("- " + .) | join("\n")' "$f" 2>/dev/null || true)"
  digressions="$(jq -r '(.digressions // []) | map("- " + .) | join("\n")' "$f" 2>/dev/null || true)"
  obstacles="$(jq -r '(.obstacles_to_autonomy // []) | map("- " + .) | join("\n")' "$f" 2>/dev/null || true)"

  entry="=== session ${session_id} (mode=${mode}, generated_at=${gen_at}) ===
source_transcript: ${src}
patterns:
${patterns:-(none)}
discoveries:
${discoveries:-(none)}
turning_points:
${turning_points:-(none)}
digressions:
${digressions:-(none)}
obstacles_to_autonomy:
${obstacles:-(none)}
"
  if (( obstacles_count > 0 )); then
    entry+="[FLAG: obstacles_to_autonomy non-empty — read source_transcript directly for full detail]
"
  fi

  entry_bytes="${#entry}"
  if (( entry_bytes > RSI_REFLECT_PER_ENTRY_CAP )); then
    entry="[Note: entry truncated to fit per-entry cap of ${RSI_REFLECT_PER_ENTRY_CAP} bytes.]
${entry:0:$RSI_REFLECT_PER_ENTRY_CAP}
"
    entry_bytes="${#entry}"
  fi

  if (( kept > 0 && used + entry_bytes > RSI_REFLECT_BYTE_BUDGET )); then
    break
  fi
  digest+="$entry"$'\n'
  used=$(( used + entry_bytes ))
  kept=$(( kept + 1 ))
done

elided=$(( total_count - kept ))
if (( elided > 0 )); then
  echo "[Note: showing ${kept} of ${total_count} sessions from the last ${RSI_REFLECT_WINDOW_HOURS}h (~${used} bytes); ${elided} elided for budget — read their transcripts directly if needed.]"
  echo
fi
printf '%s' "$digest"
```
