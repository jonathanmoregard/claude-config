# RSI-Reflect and Self-Compact Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship two coupled feature packages. **Self-compact** makes autonomous/headless Claude Code runs proactively reset to a fresh, zero-context session (instead of drifting into a lossy natural `/compact`) once cumulative context crosses ~30% of the model's window, auto-writing `tasks/mission.md` immediately before every reset so the fresh session picks up with no human involvement. **RSI-reflect** is the consumer that makes the first feature's byproduct (many more, shorter, structured session-reflect artifacts) actually useful: a new recursive-self-improvement pipeline component that mines `~/.claude/reflections/sessions/*/final.json` (already produced by the existing `session-reflect` skill) into improvement proposals, at a fraction of the cost of the current raw-transcript `daily_review` — and specifically tuned to catch self-compact's own failure modes (reset churn without progress, mission-handoff drift, deferral-instead-of-acting).

**Architecture:** Self-compact has two halves, split by what's actually possible from inside Claude Code's hook model. (1) **Interactive sessions** (`context-baggage.py`, already a `UserPromptSubmit` hook): a new, quieter 30% threshold triggers a detached, idempotent call into `session-reflect`'s existing `reflect.sh mission` worker to keep `tasks/mission.md` continuously fresh — fully autonomous, but a hook cannot force-reset a live terminal session, so the existing 70% nudge (user decides) is preserved unchanged. (2) **Headless/autonomous runs** get a new driver, `skills/self-compact/self-compact-loop.sh`, that actually performs the reset: it wraps repeated `claude -p` invocations, computes fill% from each call's own `usage` block, and — on crossing the threshold — refreshes `tasks/mission.md` via `reflect.sh mission` and starts the next iteration as a genuinely fresh session (no `--resume`). It deliberately does NOT arm the official `ralph-loop` plugin (that plugin's Stop-hook-blocking would fight the driver's own continue/reset decisions); it reuses the SAME `<promise>…</promise>` sigil convention and relies on the already-wired `compact-reinject.sh` `SessionStart` hook (fires whenever `tasks/mission.md` exists) to re-inject doctrine into every fresh session for free. RSI-reflect adds a new prompt (`recursive-self-improvement/config/rsi-reflect-prompt.md`) that is structurally identical to the existing `daily-review` prompt except Step 2 reads pre-computed reflection JSON instead of raw `.jsonl` transcripts, a new component flag (`components.rsi_reflect`, default off), a new categories.md subsection naming the exact self-compact signals to watch for, and a small repo-local wrapper (`recursive-self-improvement/bin/rsi-reflect`) that doesn't depend on the external Nix packaging the legacy `rsi-daily-review` uses.

**Tech Stack:** bash (GNU coreutils, `jq`, `awk`), Python 3 (existing hook conventions), the `claude` CLI (`-p`/`--print`, `--output-format json`, `--resume`, `--fork-session`), Claude Code hooks (`UserPromptSubmit`, `SessionStart`, `PreCompact`, `SessionEnd`), the official `ralph-loop@claude-plugins-official` plugin (read-only reference for sigil convention; not armed by self-compact), existing `session-reflect` skill (`reflect.sh mission` mode, unmodified).

**Spec:** No separate spec doc — architecture and constraints were derived directly from the existing codebase during planning (see "Context discovered during design" below in lieu of a spec doc).

## Global Constraints

- Every new script is Linux-only (GNU `date -d`, `mktemp`, `stat -c`) and requires `jq` — matches `session-reflect`'s existing hard requirement; fail loud with exit 2 on non-Linux, mirroring `reflect.sh`'s own guard.
- Nothing in this plan may force-reset a **live interactive** Claude Code session — no hook primitive exists to kill+respawn a foreground terminal session, and this plan does not attempt to fake one. Interactive sessions get automatic `mission.md` maintenance only; the actual "reset + resume" behavior is scoped to headless (`claude -p`) driver runs.
- `self-compact-loop.sh` and the official `ralph-loop` plugin must never drive the same worktree simultaneously — `self-compact-loop.sh` refuses to start if `.claude/ralph-loop.local.md` exists in `$PWD`.
- All new autonomous-run preflight guards (refuse in `$HOME`, `$HOME/.claude`, `$HOME/Repos`; require `.git`) exactly mirror `skills/orchestrate/SKILL.md`'s existing Phase 0 arm block — do not invent a different guard shape.
- `rsi_reflect` defaults to `false` in `config.json`, matching the existing `daily_review` convention (an RSI run costs real API spend; opt-in only, per CLAUDE.md: "stop and ask before... anything billed beyond the subscription").
- No changes to `nixos-config` or any repo outside this worktree — `recursive-self-improvement/bin/rsi-reflect` is a plain bash script runnable directly, not a Nix package; wiring an actual crontab entry is an explicit, separate follow-up left to the user.
- Reuse existing infrastructure over reimplementing it: `reflect.sh mission` mode, `categories.md`/`policy.md`, `push-proposals.sh`, and the `<promise>…</promise>` sigil textual convention are all consumed as-is, never forked or duplicated.

**Context discovered during design:**
- `skills/session-reflect/reflect.sh` already has a `mission` mode (synchronous, 60s budget) that writes `<cwd>/tasks/mission.md` from a session transcript via `claude --resume <sid> --fork-session --tools ""`. It's already invoked synchronously from two places: `PreCompact`'s "2nd-compact defense" and the external `idle-handoff.sh` cron timer. Nothing currently invokes it from `UserPromptSubmit` — that gap is Task 1.
- `context-baggage.py` (`UserPromptSubmit` hook) already computes context fill% and model-window size (1M vs 200K) with a carefully-tuned heuristic (`ONE_M_MODEL_PREFIXES`, `ONE_M_MARKER`, `CLAUDE_CONTEXT_MAX` override) and nudges at 70%. That heuristic is the single source of truth for model-window detection; `self-compact-loop.sh` needs an equivalent but simpler version (it already knows its own `--model` argument, so no transcript-scanning is needed) — kept as a small, explicitly cross-referenced duplicate rather than a shared subprocess call, since it's a 4-line lookup table, not shared logic worth an IPC boundary.
- The official `ralph-loop` plugin's `Stop` hook is registered **globally** for every Claude Code session (via its own `hooks/hooks.json`), and blocks stopping for ANY session whenever `.claude/ralph-loop.local.md` is present+active in `$PWD` (empty `session_id:` in the state file when armed via `safe-bash` causes the isolation check to fall through to blocking everyone in that directory — documented in `docs/superpowers/plans/2026-08-02-sigil-gated-autonomous-orchestration.md`). If `self-compact-loop.sh` also armed that state file, headless `claude -p` calls would loop internally inside ONE OS process (the Stop hook blocking would keep feeding new turns within a single invocation), and the external driver would never get a chance to intervene between iterations to reset context. Therefore `self-compact-loop.sh` must never write `.claude/ralph-loop.local.md` — it drives iteration entirely from outside, and explicitly refuses to run if that file is already present.
- `skills/orchestrate/hooks/compact-reinject.sh` (wired via `SessionStart` matcher `startup|compact|clear` in `settings.json`) already has a mission-only branch: if `.claude/ralph-loop.local.md` is absent but `tasks/mission.md` exists, it prints a re-read reminder into the fresh session's context. This means `self-compact-loop.sh` gets doctrine re-injection into every fresh session **for free**, with zero new hook wiring, as long as it keeps `tasks/mission.md` present.
- `recursive-self-improvement/config/` (config.json, prompt.md, categories.md, policy.md) is user-editable **data** read by the `recursive-self-improvement@jonathanmoregard` plugin, whose actual skill/packaging code lives in a separate marketplace directory (`~/.claude/plugins/marketplaces/jonathanmoregard`, not part of this repo). The currently-wired cron wrapper (`rsi-daily-review`) is a Nix package built from a different repo (confirmed via `logs/crontab-backup-pre-rsi-disable-20260802.txt`: `/nix/store/.../rsi-daily-review/bin/rsi-daily-review`). `rsi_reflect`'s wrapper is therefore built as a self-contained bash script in THIS repo instead, avoiding any cross-repo dependency.
- `push-proposals.sh` (repo root) already handles staging both `recursive-self-improvement/proposals/` and `proposals/` (with an intake gate and a `proposals/rsi` symlink) — reused as-is, Step 5 of both prompts already calls it.
- Active proposal directory is `recursive-self-improvement/proposals/` (referenced by `config.json`/`prompt.md`/`categories.md`); the older `improvements/` directory has only 3 stale security files from 2026-04-16 and is not part of the active pipeline — not touched by this plan.

```python
#!/usr/bin/env python3
"""
UserPromptSubmit hook: two threshold-gated behaviors on context fill.

  1. At MISSION_WRITE_THRESHOLD (default 0.30), silently (detached,
     idempotent) refreshes tasks/mission.md via session-reflect's
     `reflect.sh mission` mode, so a handoff artifact is always ready well
     before the session would need one. No user-facing output.
  2. At NUDGE_THRESHOLD (default 0.70), prints a loud nudge suggesting a
     fresh-session handoff instead of an in-place /compact (unchanged from
     the original behavior; see git history for the 0.25 -> 0.70 tuning
     rationale, empirically justified by cache-hit-ratio economics).

Context window detection (in priority order):
    1. CLAUDE_CONTEXT_MAX env var (explicit override, in tokens)
    2. Model ID prefix — Opus/Sonnet 4.x run with 1M in this setup
    3. Observed usage — if any assistant turn has exceeded 200k tokens,
       the session is 1M, regardless of model name
    4. Default 200k
"""
import json
import os
import subprocess
import sys
import time

BASE_MAX = 200_000
ONE_M = 1_000_000

MISSION_WRITE_THRESHOLD = 0.30
# How long a mission.md write is trusted before we refresh it again once
# we're past MISSION_WRITE_THRESHOLD. Tighter than idle-handoff.sh's 30min
# window (that one fires on IDLE sessions; this one fires on a LIVE session
# that's getting close to needing the handoff, so fresher state matters
# more, and the cost is still bounded by this floor either way).
MISSION_REFRESH_SECONDS = 600

# Raised from 0.25 -> 0.70 on 2026-08-08 after measuring 95.5% cache-hit
# ratio across 7 days / $3,073 spend (probes/analyze_sessions.py). At that
# hit ratio, holding baggage is cheap and resetting is expensive
# (cache_write ~$5-10 per cold event). Nudge should fire when handoff to
# a fresh session starts to pay off, not on any drift.
NUDGE_THRESHOLD = 0.70
MESSAGE_INTERVAL = 5

# Claude Code model IDs that run at 1M context by default. Prefixes, so
# dated variants (claude-opus-4-1-20250805) match too.
ONE_M_MODEL_PREFIXES = (
    "claude-opus-4-",
    "claude-sonnet-4-",
    "claude-opus-5",
    "claude-sonnet-5",
)

# Explicit 1M marker in the model ID, e.g. `claude-opus-5[1m]`. Checked
# before the prefix list so it keeps working across model generations
# without another edit here — the prefix list going stale is exactly how
# this hook came to report 89% full during a session that was at 18% of a
# 1M window (every reading was fullness-of-200k).
ONE_M_MARKER = "[1m]"

REFLECT_SH = os.path.expanduser("~/.claude/skills/session-reflect/reflect.sh")


def detect_max_tokens(model: str | None, observed_max: int) -> int:
    override = os.environ.get("CLAUDE_CONTEXT_MAX")
    if override:
        try:
            return int(override)
        except ValueError:
            pass
    if model:
        if ONE_M_MARKER in model.lower():
            return ONE_M
        if any(model.startswith(p) for p in ONE_M_MODEL_PREFIXES):
            return ONE_M
    if observed_max > BASE_MAX:
        return ONE_M
    return BASE_MAX


def maybe_write_mission(session_id, transcript_path, cwd):
    """Detached, idempotent refresh of tasks/mission.md. Never blocks the
    hook and never raises — a failure here must not affect the user's turn."""
    if not session_id or not cwd:
        return
    mission_path = os.path.join(cwd, "tasks", "mission.md")
    if os.path.exists(mission_path):
        age = time.time() - os.path.getmtime(mission_path)
        if age < MISSION_REFRESH_SECONDS:
            return
    if not os.path.isfile(REFLECT_SH):
        return
    payload = json.dumps(
        {
            "session_id": session_id,
            "transcript_path": transcript_path,
            "cwd": cwd,
            "hook_event_name": "UserPromptSubmit",
        }
    )
    try:
        proc = subprocess.Popen(
            ["bash", REFLECT_SH, "mission"],
            stdin=subprocess.PIPE,
            stdout=subprocess.DEVNULL,
            stderr=subprocess.DEVNULL,
            start_new_session=True,
        )
        proc.stdin.write(payload.encode())
        proc.stdin.close()
    except Exception:
        pass


def main():
    try:
        data = json.load(sys.stdin)
    except Exception:
        sys.exit(0)

    transcript_path = data.get("transcript_path", "")
    if not transcript_path or not os.path.exists(transcript_path):
        sys.exit(0)

    file_size = os.path.getsize(transcript_path)

    user_msg_count = 0
    last_usage = None
    last_model = None
    observed_max = 0

    with open(transcript_path, "r", errors="replace") as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
            try:
                obj = json.loads(line)
            except json.JSONDecodeError:
                continue

            obj_type = obj.get("type")

            if obj_type == "user":
                user_msg_count += 1
            elif obj_type == "assistant":
                msg = obj.get("message", {})
                model = msg.get("model")
                if model and model != "<synthetic>":
                    last_model = model
                usage = msg.get("usage")
                if usage:
                    last_usage = usage
                    total = (
                        usage.get("input_tokens", 0)
                        + usage.get("cache_creation_input_tokens", 0)
                        + usage.get("cache_read_input_tokens", 0)
                    )
                    if total > observed_max:
                        observed_max = total

    if user_msg_count == 0 or user_msg_count % MESSAGE_INTERVAL != 0:
        sys.exit(0)

    max_tokens = detect_max_tokens(last_model, observed_max)

    if last_usage:
        total_tokens = (
            last_usage.get("input_tokens", 0)
            + last_usage.get("cache_creation_input_tokens", 0)
            + last_usage.get("cache_read_input_tokens", 0)
        )
        fill_pct = total_tokens / max_tokens
    else:
        fill_pct = file_size / (max_tokens * 4)

    if fill_pct >= MISSION_WRITE_THRESHOLD:
        maybe_write_mission(data.get("session_id"), transcript_path, data.get("cwd"))

    if fill_pct < NUDGE_THRESHOLD:
        sys.exit(0)

    pct_display = int(fill_pct * 100)
    message = (
        f"Context is {pct_display}% full ({user_msg_count} messages in this session; "
        f"window: {max_tokens // 1000}k tokens). "
        "At this fill, a fresh-session handoff via tasks/mission.md is usually cheaper "
        "than an in-place /compact: --fork-session on a warm cache measured ~77% hit "
        "(session-reflect empirical), while /compact invalidates the prefix and forces "
        "cache_write on subsequent turns. tasks/mission.md has been kept fresh "
        "automatically since 30% fill. "
        "Suggest to the user: (a) start a fresh session in the same cwd and load it, "
        "OR (b) continue here and accept the drift. Ask which."
    )
    print(json.dumps({"hookSpecificOutput": {"hookEventName": "UserPromptSubmit", "additionalContext": message}}))


if __name__ == "__main__":
    main()
```

```bash
#!/usr/bin/env bash
# self-compact-loop.sh — headless autonomous driver that resets to a fresh
# `claude -p` session (instead of letting context grow into a natural,
# lossy /compact) once cumulative context crosses a threshold fraction of
# the model's context window.
#
# Usage:
#   self-compact-loop.sh "<mission prompt>" --sigil "<completion statement>" \
#     [--threshold 0.30] [--max-iterations 25] [--max-seconds 14400] \
#     [--model claude-opus-5]
#
# Requires: bash, jq, awk, find, git, the `claude` CLI on PATH.
# Must be run from a dedicated worktree root — same rule as
# skills/orchestrate/SKILL.md Phase 0.
#
# Deliberately does NOT arm the official ralph-loop plugin: that plugin's
# Stop hook blocks-in-place within ONE claude process, which would prevent
# this script from ever getting a chance to intervene between iterations.
# Refuses to run if a ralph-loop state file is already armed in $PWD.
set -euo pipefail

if [[ "$(uname -s)" != "Linux" ]]; then
  echo "self-compact-loop.sh: Linux only" >&2
  exit 2
fi

MISSION_PROMPT="${1:-}"
[[ -n "$MISSION_PROMPT" ]] || { echo "REFUSE: mission prompt (arg 1) required"; exit 1; }
shift || true

THRESHOLD="0.30"
MAX_ITERATIONS="25"
MAX_SECONDS="14400"
MODEL="claude-opus-5"
SIGIL=""

while (( $# > 0 )); do
  case "$1" in
    --threshold) THRESHOLD="$2"; shift 2 ;;
    --max-iterations) MAX_ITERATIONS="$2"; shift 2 ;;
    --max-seconds) MAX_SECONDS="$2"; shift 2 ;;
    --model) MODEL="$2"; shift 2 ;;
    --sigil) SIGIL="$2"; shift 2 ;;
    *) echo "REFUSE: unknown argument '$1'"; exit 1 ;;
  esac
done

[[ -n "$SIGIL" ]] || { echo "REFUSE: --sigil is required — no placeholder default (an unsubstituted sigil can never match, so the loop would only end at max-iterations)"; exit 1; }
case "$SIGIL" in *'"'*|*'$'*|*'`'*|*'\'*)
  echo 'REFUSE: sigil must not contain " $ ` or \ (breaks the <promise> grep and any downstream YAML)'; exit 1;;
esac

# --- Preflight (mirrors skills/orchestrate/SKILL.md Phase 0) ----------------
case "$PWD" in
  "$HOME"|"$HOME/.claude"|"$HOME/Repos") echo "REFUSE: run only from a dedicated worktree root"; exit 1;;
esac
[[ -e .git ]] || { echo "REFUSE: not a repo/worktree root"; exit 1; }
if [[ -f .claude/ralph-loop.local.md ]]; then
  echo "REFUSE: ralph-loop is armed in this directory (.claude/ralph-loop.local.md exists) — self-compact-loop.sh and the ralph-loop plugin must not drive the same worktree at once."
  exit 1
fi

REFLECT_SH="$HOME/.claude/skills/session-reflect/reflect.sh"
[[ -f "$REFLECT_SH" ]] || { echo "REFUSE: session-reflect not found at $REFLECT_SH — mission.md refresh would silently fail on every reset"; exit 1; }

# Context-window size for the chosen model. Mirrors context-baggage.py's
# ONE_M_MODEL_PREFIXES / ONE_M_MARKER table — keep the two in sync; this is
# a small enough lookup that a cross-process call isn't worth the coupling,
# but a prefix-list edit in one place needs the same edit in the other.
MAX_TOKENS=200000
case "$MODEL" in
  claude-opus-4-*|claude-sonnet-4-*|claude-opus-5*|claude-sonnet-5*) MAX_TOKENS=1000000 ;;
esac
[[ "$MODEL" == *"[1m]"* ]] && MAX_TOKENS=1000000
: "${SELF_COMPACT_MAX_TOKENS_OVERRIDE:=}"
[[ -n "$SELF_COMPACT_MAX_TOKENS_OVERRIDE" ]] && MAX_TOKENS="$SELF_COMPACT_MAX_TOKENS_OVERRIDE"

mkdir -p tasks
[[ -f tasks/progress.md ]] || : > tasks/progress.md
[[ -f tasks/session-constraints.md ]] || : > tasks/session-constraints.md

if [[ ! -f tasks/mission.md ]]; then
  cat > tasks/mission.md <<EOF
# Mission

$MISSION_PROMPT

## Sigil
$SIGIL

## Cancel
Delete tasks/mission.md and kill this script's process to cancel.

## Status
Bootstrapped by self-compact-loop.sh, iteration 0, not yet started.
EOF
fi

log() { printf '%s %s\n' "$(date -u +%Y-%m-%dT%H:%M:%SZ)" "$*" | tee -a tasks/self-compact.log; }

iteration=0
resets=0
session_id=""
start_ts=$(date +%s)

write_state() {
  jq -n --argjson iter "$iteration" --argjson resets "$resets" \
    --arg last_sid "$session_id" --arg updated "$(date -u +%Y-%m-%dT%H:%M:%SZ)" \
    '{iteration:$iter, resets:$resets, last_session_id:$last_sid, updated_at:$updated}' \
    > tasks/self-compact-state.json
}

while (( iteration < MAX_ITERATIONS )); do
  now=$(date +%s)
  if (( now - start_ts >= MAX_SECONDS )); then
    log "STOP: wall-clock cap (${MAX_SECONDS}s) reached at iteration $iteration"
    write_state
    exit 1
  fi
  iteration=$((iteration + 1))

  if [[ -z "$session_id" ]]; then
    PROMPT="Read tasks/mission.md, tasks/session-constraints.md, and tasks/progress.md, then continue autonomously from where progress.md left off (empty progress.md = start at the first unchecked item). Emit <promise>${SIGIL}</promise> ALONE as your final message only when that statement is literally true."
    RESUME_ARGS=()
  else
    PROMPT="Continue."
    RESUME_ARGS=(--resume "$session_id")
  fi

  log "iteration $iteration: calling claude (resume=${session_id:-<fresh>})"
  set +e
  OUT=$(claude -p "$PROMPT" "${RESUME_ARGS[@]}" --model "$MODEL" --output-format json)
  rc=$?
  set -e
  if (( rc != 0 )); then
    log "STOP: claude exited $rc at iteration $iteration"
    write_state
    exit 1
  fi

  session_id=$(jq -r '.session_id // empty' <<<"$OUT")
  result_text=$(jq -r '.result // empty' <<<"$OUT")

  if grep -qF "<promise>${SIGIL}</promise>" <<<"$result_text"; then
    log "DONE: sigil detected at iteration $iteration (resets=$resets)"
    write_state
    exit 0
  fi

  usage_json=$(jq -c '.usage // {}' <<<"$OUT")
  total=$(jq -n --argjson u "$usage_json" \
    '($u.input_tokens // 0) + ($u.cache_creation_input_tokens // 0) + ($u.cache_read_input_tokens // 0)')
  fill_pct=$(jq -n --argjson t "$total" --argjson m "$MAX_TOKENS" 'if $m > 0 then $t / $m else 0 end')

  write_state

  if awk -v f="$fill_pct" -v th="$THRESHOLD" 'BEGIN{exit !(f>=th)}'; then
    log "RESET: fill=${fill_pct} >= threshold=${THRESHOLD} at iteration $iteration — refreshing mission.md and starting a fresh session"
    if [[ -z "$session_id" ]]; then
      log "WARN: no session_id returned by claude; cannot refresh mission.md via reflect.sh this round, continuing with existing mission.md"
    else
      transcript=$(find "$HOME/.claude/projects" -maxdepth 2 -name "${session_id}.jsonl" -print -quit 2>/dev/null || true)
      if [[ -z "$transcript" ]]; then
        log "WARN: transcript for session $session_id not found under ~/.claude/projects; skipping mission.md refresh this round"
      else
        MISSION_PAYLOAD=$(jq -cn --arg sid "$session_id" --arg tp "$transcript" --arg cwd "$PWD" \
          '{session_id:$sid, transcript_path:$tp, cwd:$cwd, hook_event_name:"SelfCompact"}')
        if ! echo "$MISSION_PAYLOAD" | bash "$REFLECT_SH" mission; then
          log "WARN: reflect.sh mission exited non-zero; continuing with existing mission.md"
        fi
      fi
    fi
    resets=$((resets + 1))
    session_id=""
    write_state
  fi
done

log "STOP: max-iterations (${MAX_ITERATIONS}) reached (resets=$resets)"
write_state
exit 1
```

---

# Self-Compact

Two halves, split by what's actually possible from inside Claude Code's hook model:

1. **Interactive sessions** — `context-baggage.py` (a `UserPromptSubmit` hook,
   already wired) silently refreshes `tasks/mission.md` once fill crosses
   30%, via `session-reflect`'s existing `reflect.sh mission` mode. No
   hook can force a live terminal session to reset itself — this half is
   "always have a fresh handoff ready," not "auto-reset." The existing
   70% nudge (asks the user to decide) is unchanged.
2. **Headless/autonomous runs** — `self-compact-loop.sh` actually
   performs the reset. It wraps repeated `claude -p` calls, computes
   fill% from each call's own `usage` block, and on crossing
   `--threshold` (default 0.30): refreshes `tasks/mission.md` via
   `reflect.sh mission` against the just-finished session, then starts
   the next iteration as a genuinely fresh `claude -p` call (no
   `--resume`).

## Why not just arm ralph-loop and let it run long?

The official `ralph-loop` plugin's `Stop` hook blocks-in-place **within
one `claude` process** — it re-feeds the loop prompt as a new turn inside
the same session, so context keeps growing until a natural (lossy)
`/compact` eventually fires. That's the exact "fetching water in a sieve"
failure mode documented in
`recursive-self-improvement/proposals/2026-08-02-repeat-compact-in-session.md`.
`self-compact-loop.sh` drives iteration from OUTSIDE the `claude` process
instead, so it can genuinely start a fresh, zero-context session rather
than merely feeding another turn into a growing one.

**`self-compact-loop.sh` and an armed `ralph-loop` must never run in the
same worktree.** Both would try to decide "continue vs stop" for the same
directory, and `ralph-loop`'s Stop-hook blocking would prevent
`self-compact-loop.sh`'s external loop from ever observing a process
exit between iterations. `self-compact-loop.sh` refuses to start if
`.claude/ralph-loop.local.md` is present.

## Free doctrine re-injection

`self-compact-loop.sh` does not need to arm any new hook: it keeps
`tasks/mission.md` present, and the already-wired
`skills/orchestrate/hooks/compact-reinject.sh`
(`SessionStart` matcher `startup|compact|clear`) already has a
mission-only branch that reminds every fresh session to re-read it. Each
reset gets doctrine re-injection automatically.

```bash
#!/usr/bin/env bash
# rsi-reflect — headless wrapper that runs the RSI reflect-artifact review.
# Mirrors the (Nix-packaged, external) rsi-daily-review wrapper's component
# gate, but lives entirely in this repo so it's directly runnable/testable
# without depending on nixos-config packaging. Wiring an actual cron entry
# is a separate, deliberate step, left to the user.
set -euo pipefail

RSI_ROOT="$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")/.." && pwd)"
CONFIG="$RSI_ROOT/config/config.json"
PROMPT="$RSI_ROOT/config/rsi-reflect-prompt.md"

if [[ ! -f "$CONFIG" ]]; then
  echo "rsi-reflect: config.json missing at $CONFIG; nothing to do."
  exit 0
fi

ENABLED="$(jq -r '.components.rsi_reflect // false' "$CONFIG")"
if [[ "$ENABLED" != "true" ]]; then
  echo "rsi-reflect: disabled in components.rsi_reflect; nothing to do."
  exit 0
fi

[[ -f "$PROMPT" ]] || { echo "rsi-reflect: prompt file missing at $PROMPT" >&2; exit 1; }

claude --model opus --print \
  --allowedTools "Read Write($HOME/.claude/recursive-self-improvement/proposals/*) Glob Grep Bash($HOME/.claude/push-proposals.sh)" \
  -p "$(cat "$PROMPT")"
```

## Deliberately out of scope (YAGNI, revisit only on demand)

- **Forcing a reset of a live interactive TTY session.** No Claude Code hook can kill+respawn its own parent terminal session. Interactive sessions get automatic `mission.md` maintenance (Task 1) and the existing loud 70% nudge; the human decides when to actually start fresh.
- **Nix packaging / crontab wiring for `rsi-reflect` in `nixos-config`.** Different repo, not touched here. `recursive-self-improvement/bin/rsi-reflect` is directly runnable (`bash recursive-self-improvement/bin/rsi-reflect`) once `components.rsi_reflect` is flipped to `true`; wiring a cron entry is a deliberate follow-up.
- **Automated pruning of `~/.claude/reflections/sessions/`.** `rsi-reflect` is a reader, not a garbage collector — the existing "do not automate deletion" caveat in `session-reflect/README.md` still applies.
- **Modifying the official `ralph-loop` plugin.** `self-compact-loop.sh` is a deliberately independent, non-overlapping driver (refuses to run when ralph-loop is armed in the same directory) rather than a patch to the plugin.
- **Auto-enabling `rsi_reflect` or wiring a live cron entry as part of this plan.** Defaults to `false`, matching `daily_review`'s existing convention — the user opts in explicitly in a follow-up.
- **A shared bash/Python library for the model-window-detection heuristic.** `context-baggage.py` (transcript-scanning) and `self-compact-loop.sh` (already knows its own `--model` argument) have different enough inputs that a shared subprocess call isn't worth the coupling for a 4-line lookup table; kept as two small, cross-referenced copies instead.
