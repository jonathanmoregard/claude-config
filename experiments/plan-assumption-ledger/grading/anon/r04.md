# RSI Reflect + Self-Compact Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship two complementary packages. (1) **rsi-reflect** — wire `session-reflect`'s structured per-session artifacts (`patterns`/`discoveries`/`turning_points`/`digressions`/`obstacles_to_autonomy`) into the RSI daily-review pipeline as the primary, cheap signal source, falling back to raw transcript reads only when no artifact exists. (2) **self-compact** — during an armed `ralph-loop` autonomous run, proactively refresh `tasks/mission.md`/`tasks/progress.md` and attempt a real context reset once context fill crosses ~30% of the window, instead of silently accumulating context until Claude Code's own auto-compact eventually fires.

**Architecture:** rsi-reflect is a pure prompt/config change (`recursive-self-improvement/config/prompt.md`, `categories.md`) plus a grep-based content smoke test — no new runtime code, since the daily-review agent reads these files live off disk. self-compact adds a new `UserPromptSubmit` hook (`self-compact-nudge.py`, sibling to `context-baggage.py`) gated on `.claude/ralph-loop.local.md` being armed, sharing a newly-extracted `context_fill.py` module with `context-baggage.py` for fill-percentage detection. Because whether the model can force a *real* compaction from inside a turn is an unverified platform question, Task 5 is an empirical spike that determines which of two `additionalContext` instruction variants ships.

**Tech Stack:** bash (GNU/Linux only, matching `session-reflect`'s existing constraint), Python 3 stdlib only (matching `context-baggage.py`/`permission-ledger`), Claude Code hooks (`UserPromptSubmit`, existing `PreCompact`/`SessionStart` untouched), `unittest` (matching `permission-ledger/tests/test_hook.py` style).

**Spec:** none pre-existing — scope derived directly from repo investigation this session (see Context below), following the precedent set by `docs/superpowers/plans/2026-08-02-sigil-gated-autonomous-orchestration.md` for documenting discovered constraints inline in lieu of a separate spec doc.

```python
#!/usr/bin/env python3
"""Shared context-window fill detection for context-baggage.py and
self-compact-nudge.py. Extracted so the two hooks can never drift on the
model-prefix list or the usage-parsing logic — see context-baggage.py's own
history comment about a stale prefix list once reporting 89% full during an
18%-full session.
"""
import json
import os

BASE_MAX = 200_000
ONE_M = 1_000_000

ONE_M_MODEL_PREFIXES = (
    "claude-opus-4-",
    "claude-sonnet-4-",
    "claude-opus-5",
    "claude-sonnet-5",
)
ONE_M_MARKER = "[1m]"


def detect_max_tokens(model: str | None, observed_max: int) -> int:
    override = os.environ.get("CLAUDE_CONTEXT_MAX")
    if override:
        try:
            return int(override)
        except ValueError:
            pass
    if model:
        if ONE_M_MARKER in model.lower():
            return ONE_M
        if any(model.startswith(p) for p in ONE_M_MODEL_PREFIXES):
            return ONE_M
    if observed_max > BASE_MAX:
        return ONE_M
    return BASE_MAX


def compute_fill_pct(transcript_path: str):
    """Returns (fill_pct, user_msg_count, max_tokens, last_model) or None
    if the transcript is missing/unreadable."""
    if not transcript_path or not os.path.exists(transcript_path):
        return None

    file_size = os.path.getsize(transcript_path)
    user_msg_count = 0
    last_usage = None
    last_model = None
    observed_max = 0

    with open(transcript_path, "r", errors="replace") as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
            try:
                obj = json.loads(line)
            except json.JSONDecodeError:
                continue

            obj_type = obj.get("type")
            if obj_type == "user":
                user_msg_count += 1
            elif obj_type == "assistant":
                msg = obj.get("message", {})
                model = msg.get("model")
                if model and model != "<synthetic>":
                    last_model = model
                usage = msg.get("usage")
                if usage:
                    last_usage = usage
                    total = (
                        usage.get("input_tokens", 0)
                        + usage.get("cache_creation_input_tokens", 0)
                        + usage.get("cache_read_input_tokens", 0)
                    )
                    if total > observed_max:
                        observed_max = total

    max_tokens = detect_max_tokens(last_model, observed_max)

    if last_usage:
        total_tokens = (
            last_usage.get("input_tokens", 0)
            + last_usage.get("cache_creation_input_tokens", 0)
            + last_usage.get("cache_read_input_tokens", 0)
        )
        fill_pct = total_tokens / max_tokens
    else:
        fill_pct = file_size / (max_tokens * 4)

    return (fill_pct, user_msg_count, max_tokens, last_model)
```

```python
#!/usr/bin/env python3
"""
UserPromptSubmit hook: during an armed ralph-loop, once context fill crosses
SELF_COMPACT_THRESHOLD (default 30% of the detected window), instructs
Claude to refresh tasks/mission.md and tasks/progress.md, then reset context
via the SlashCommand tool (`/compact`).

Only active when `.claude/ralph-loop.local.md` exists in cwd (autonomous
mode) — interactive sessions keep using context-baggage.py's ask-the-user
nudge at 70%, unchanged. Silent (no re-nag) while tasks/mission.md is fresh,
so a single instruction per stale-window crossing, not one every iteration.
"""
import json
import os
import sys
import time

from context_fill import compute_fill_pct

SELF_COMPACT_THRESHOLD = float(os.environ.get("SELF_COMPACT_THRESHOLD", "0.30"))
MISSION_FRESH_SECONDS = int(os.environ.get("SELF_COMPACT_MISSION_FRESH_SECONDS", "300"))
DISABLE_FLAG = os.environ.get(
    "SELF_COMPACT_DISABLE_FLAG",
    os.path.expanduser("~/.claude/self-compact.disable"),
)


def main():
    if os.path.exists(DISABLE_FLAG):
        sys.exit(0)

    try:
        data = json.load(sys.stdin)
    except Exception:
        sys.exit(0)

    cwd = data.get("cwd", "")
    if not cwd:
        sys.exit(0)

    ralph_state = os.path.join(cwd, ".claude", "ralph-loop.local.md")
    if not os.path.isfile(ralph_state):
        sys.exit(0)

    transcript_path = data.get("transcript_path", "")
    result = compute_fill_pct(transcript_path)
    if result is None:
        sys.exit(0)
    fill_pct, _user_msg_count, max_tokens, _last_model = result

    if fill_pct < SELF_COMPACT_THRESHOLD:
        sys.exit(0)

    mission_path = os.path.join(cwd, "tasks", "mission.md")
    if os.path.isfile(mission_path):
        age = time.time() - os.path.getmtime(mission_path)
        if age < MISSION_FRESH_SECONDS:
            sys.exit(0)

    pct_display = int(fill_pct * 100)
    message = (
        f"[self-compact] Context is {pct_display}% full ({max_tokens // 1000}k window) "
        f"during an armed ralph-loop — no one is here to decide manually, so do this "
        f"now before continuing the mission: "
        f"(1) write/refresh tasks/mission.md (done/next/blocked/open questions — see "
        f"skills/session-reflect/prompts/mission.md for the format) and tasks/progress.md; "
        f"(2) call the SlashCommand tool with `/compact` to reset context now; "
        f"(3) after compaction, SessionStart(compact) re-injects the ralph doctrine and "
        f"the mission.md pointer automatically — resume from mission.md's Next section, "
        f"do not ask the user."
    )
    print(json.dumps({"hookSpecificOutput": {"hookEventName": "UserPromptSubmit", "additionalContext": message}}))


if __name__ == "__main__":
    main()
```

## Assumptions

- **Reused component:** `skills/session-reflect/prompts/mission.md` was built as the format template for both `reflect.sh mission` (async, idle-triggered) and the general "write tasks/mission.md" instruction already in `CLAUDE.md`. self-compact reuses it a third way — as the format reference for a *live, synchronous* write by the model itself mid-turn, during an active ralph loop. This differs from its two existing uses (always previously invoked either by a human directive or an async subprocess, never by an automated hook mid-turn) but the file's own content ("Write tasks/mission.md for the current project... goes on disk before context is reset or the session goes idle") already anticipates exactly this trigger. No changes to `prompts/mission.md` needed.
- **Reused component:** `context-baggage.py`'s fill-detection logic was built for a 70%-threshold interactive ask-the-user nudge. self-compact reuses the same detection at a lower (30%) threshold for a different purpose (autonomous action, not a question). The refactor in Task B1 makes this reuse structural (shared module) rather than copy-pasted, so a future threshold-model fix (like the historical stale-prefix-list bug) fixes both call sites at once.
- **Not reused:** `idle-handoff.sh`'s async mission-write mechanism (`reflect.sh mission`, forking the transcript from an external cron process) was deliberately NOT reused for self-compact, because it's built for *idle* (no live process attached) sessions specifically and explicitly documents an error mode for live sessions. self-compact's live-model-writes-it-itself approach avoids that error mode entirely.
- **Fallback path (Task B4B):** if Task B3's spike shows the model cannot force a real reset mid-turn, self-compact still ships real value (proactive mission.md/progress.md freshness ahead of whatever eventually triggers a real compaction) but does not literally "reset" context at 30% — flagged explicitly in the nudge message itself so this isn't a silent gap, and recorded in the Task B7 memory for future sessions to know without re-deriving it.
