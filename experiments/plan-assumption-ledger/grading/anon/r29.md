# RSI-Reflect + Self-Compact Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship two coupled feature packages: (1) **self-compact** — `context-baggage.py` autonomously writes `tasks/mission.md` when context crosses 70% used (30% remaining) instead of asking the user, so the harness's own compaction (auto or manual) is never lossy and Claude never stalls waiting for a decision; (2) **rsi-reflect** — wire `session-reflect`'s per-session structured artifacts into the RSI daily-review pipeline as primary evidence, replacing full-transcript reads with cheap pre-extracted JSON.

**Architecture:** Self-compact extends the existing `context-baggage.py` UserPromptSubmit hook (already computes fill% correctly for 1M-context models, already fires at the right threshold) to spawn a detached, non-blocking call into the existing `reflect.sh mission` mode, then swaps its user-facing message from "ask which" to "proceeding autonomously." No new hooks, no `settings.json` changes — the resume side (`compact-reinject.sh`) already handles "mission.md exists → re-read it" generically. Rsi-reflect rewrites two prompt files (`recursive-self-improvement/config/prompt.md`, `categories.md`) to prefer `~/.claude/reflections/sessions/*/final.json` over raw transcripts, with raw transcripts as an explicit fallback; a bash regression-guard script keeps the two subsystems' schemas from silently drifting apart. Neither package invents a mechanism to force `/compact` — that tool doesn't exist for the model (verified against Claude Code's own source: builtin commands are filtered out of the model-facing `SlashCommand` tool).

**Tech Stack:** Python 3 (hook scripts), bash (session-reflect, test scripts), Claude Code hooks (`UserPromptSubmit`, already-wired `PreCompact`/`SessionStart`), markdown prompt files (RSI review agent).

**Spec:** None — scoped directly from repository investigation (no separate spec doc; see Context below for the evidence trail).

## Context (read before starting — this is why the tasks are shaped this way)

- `context-baggage.py` (repo root, wired in `settings.json` as a `UserPromptSubmit` hook) already computes `fill_pct` correctly across 200k/1M context windows and fires at `THRESHOLD = 0.70` every `MESSAGE_INTERVAL = 5` user messages once crossed. **Do not change these two constants** — 0.70 used = 30% remaining is already exactly the number requested. The only thing wrong with it today is that its message asks the user to choose between three options instead of acting.
- `skills/session-reflect/reflect.sh mission` (already implemented, already used by two other callers — the in-session 2nd-PreCompact defense and the `scripts/idle-handoff.sh` cron job) synchronously resumes the current session with a cheap Haiku call and writes `<cwd>/tasks/mission.md` atomically. It expects a JSON payload on stdin with `session_id`, `transcript_path`, `cwd`, `hook_event_name` — the exact fields already present in `context-baggage.py`'s hook payload.
- `skills/orchestrate/hooks/compact-reinject.sh` (`SessionStart`, matcher `startup|compact|clear`, already wired) already prints a "re-read `tasks/mission.md`" reminder into context whenever that file exists post-compact/clear/startup, with **no dependency on a ralph-loop being armed**. This is the entire "picks up autonomously" half of self-compact, and it needs zero changes.
- Claude Code's model-facing `SlashCommand` tool (`~/Repos/claude-code/src/commands.ts`, `getSlashCommandToolSkills`) explicitly filters to `cmd.source !== 'builtin'` — built-in commands including `/compact` are **not invocable by the model**. Compaction only happens via the user typing it, or Claude Code's own internal automatic/reactive compaction near the true context ceiling. Self-compact's job is therefore: keep `tasks/mission.md` fresh at all times past the threshold, and stop the agent from pausing to ask — not to manufacture a compact event.
- `recursive-self-improvement/config/prompt.md` Step 2 currently instructs the daily-review agent to find and read every `.jsonl` modified in the last 24h directly. `config.json` has `components.daily_review: false` today (this is a paid nightly Opus pass over full transcripts — expensive). `session-reflect/README.md` explicitly states cross-session synthesis over its artifacts "is a separate later system that reads these artifacts" — unbuilt until this plan.
- The reflect artifact schema (`final.json` / `checkpoints/*.json`) has five arrays: `patterns`, `discoveries`, `turning_points`, `digressions`, `obstacles_to_autonomy` — these map close to 1:1 onto RSI's four categories (productivity/automation/alignment/wellbeing), which is what makes this wiring cheap and low-risk rather than a rewrite.

## Global Constraints

- Never instruct or design toward the model invoking `/compact` itself — confirmed unavailable (see Context above).
- Reuse `THRESHOLD = 0.70` / `MESSAGE_INTERVAL = 5` in `context-baggage.py` unchanged.
- Any new background process spawned from a hook must be non-blocking (`start_new_session=True`, detached) — hooks must never block on model latency, matching `session-reflect`'s own stated design constraint.
- Follow the existing kill-switch convention (`~/.claude/idle-handoff.disable`) for any new autonomous-write behavior — add `~/.claude/self-compact.disable`.
- `REFLECT_SH` path is hardcoded to `~/.claude/skills/session-reflect/reflect.sh` (absolute, not worktree-relative) — this matches `scripts/idle-handoff.sh`'s existing convention exactly (this repo's runtime hooks assume deployment at the real `~/.claude`, distinct from a dev worktree). Do not "fix" this to be worktree-relative.
- Enabling `recursive-self-improvement/config.json`'s `daily_review: true` triggers real nightly Opus spend. Per this repo's own `CLAUDE.md` ("Stop and ask before: ... anything billed beyond the subscription"), this plan **implements the capability but does not flip the toggle** — that decision is left to the user as an explicit, documented, one-line follow-up.
- No `settings.json` changes are required by either package (both hooks involved are already wired).

## Assumptions (load-bearing reuse)

- **`compact-reinject.sh` reuse**: built originally for ralph-loop doctrine re-injection, but its mission-only branch (`if [[ ! -f "$STATE" ]]`) already generically re-injects a "re-read `tasks/mission.md`" reminder for *any* project with that file present, regardless of whether a ralph loop is armed. No divergence between what it was built for and what self-compact needs — reused as-is, zero code changes, verified by reading its current source in full.
- **`reflect.sh mission` reuse**: built for idle-session handoff and the in-session 2nd-compact defense; both callers construct their own JSON payload and invoke it the same way self-compact will. No interface changes needed — it already tolerates being invoked from an arbitrary caller as long as the payload shape matches.
- **RSI daily-review reuse**: `prompt.md`/`categories.md` were built assuming raw-transcript-only evidence. This plan changes the *evidence source*, not the analysis rules (Step 3's "Skip — healthy collaboration" / "What to flag" logic is untouched) — a smaller, load-bearing change than a rewrite.

```python
def make_transcript(path, n_user=25, model="claude-opus-5", total_tokens=700_000):
    """25 user turns (multiple of MESSAGE_INTERVAL=5), last assistant usage
    high enough to cross THRESHOLD=0.70 of a 1M window."""
    lines = []
    for i in range(n_user):
        lines.append(json.dumps({"type": "user", "message": {"role": "user", "content": "hi"}}))
        lines.append(json.dumps({
            "type": "assistant",
            "message": {
                "role": "assistant",
                "model": model,
                "content": [{"type": "text", "text": "ok"}],
                "usage": {"input_tokens": total_tokens, "cache_creation_input_tokens": 0, "cache_read_input_tokens": 0},
            },
        }))
    with open(path, "w") as f:
        f.write("\n".join(lines) + "\n")

    def test_spawns_bash_reflect_sh_mission_with_payload_on_stdin(self):
        calls = {}

        class FakeProc:
            def __init__(self):
                self.stdin = io.BytesIO()
                self._written = b""

            def write(self, data):
                self._written += data

        fake_proc = FakeProc()

        class Stdin:
            def write(self, data):
                written["payload"] = data

            def close(self):
                written["closed"] = True

class TestMainAutonomousBehavior(unittest.TestCase):
    def _run_main(self, payload):
        stdin = io.StringIO(json.dumps(payload))
        stdout = io.StringIO()
        with patch.object(sys, "stdin", stdin), patch.object(sys, "stdout", stdout):
            try:
                cb.main()
            except SystemExit:
                pass
        return stdout.getvalue()

    def test_below_threshold_emits_nothing_and_does_not_spawn(self):
        with tempfile.TemporaryDirectory() as d:
            transcript = os.path.join(d, "t.jsonl")
            make_transcript(transcript, n_user=25, total_tokens=100_000)  # well under 70% of 1M
            with patch.object(cb.subprocess, "Popen") as popen:
                out = self._run_main({"transcript_path": transcript, "cwd": d, "session_id": "s1", "hook_event_name": "UserPromptSubmit"})
            self.assertEqual(out.strip(), "")
            popen.assert_not_called()

    def test_above_threshold_no_mission_file_spawns_and_message_is_autonomous(self):
        with tempfile.TemporaryDirectory() as d:
            transcript = os.path.join(d, "t.jsonl")
            make_transcript(transcript, n_user=25, total_tokens=800_000)  # 80% of 1M > 0.70
            with patch.object(cb.subprocess, "Popen") as popen:
                fake = popen.return_value
                fake.stdin.write = lambda *_: None
                fake.stdin.close = lambda: None
                out = self._run_main({"transcript_path": transcript, "cwd": d, "session_id": "s1", "hook_event_name": "UserPromptSubmit"})

            msg = json.loads(out)["hookSpecificOutput"]["additionalContext"]
```

```python
def mission_is_fresh(cwd: str, now: float, fresh_seconds: int = MISSION_FRESH_SECONDS) -> bool:
    mission_path = os.path.join(cwd, "tasks", "mission.md")
    try:
        mtime = os.path.getmtime(mission_path)
    except OSError:
        return False
    return (now - mtime) < fresh_seconds


def spawn_mission_write(session_id: str, transcript_path: str, cwd: str, hook_event_name: str) -> None:
    """Fire-and-forget: detach `reflect.sh mission` so this hook never blocks
    on model latency. Best-effort — a spawn failure must never break the
    UserPromptSubmit turn."""
    payload = json.dumps({
        "session_id": session_id,
        "transcript_path": transcript_path,
        "cwd": cwd,
        "hook_event_name": hook_event_name,
    }).encode()
    try:
        proc = subprocess.Popen(
            ["bash", REFLECT_SH, "mission"],
            stdin=subprocess.PIPE,
            stdout=subprocess.DEVNULL,
            stderr=subprocess.DEVNULL,
            start_new_session=True,
        )
        proc.stdin.write(payload)
        proc.stdin.close()
    except OSError:
        pass
```

- [ ] **Step 1: Write the regression-guard script**

This is a deterministic drift-check, not a functional test of the LLM prompt (prompt content isn't unit-testable; see Step 3 for the real validation path). It fails loudly if `reflect.sh`'s schema or default path ever changes without the RSI prompts being updated to match.

Create `recursive-self-improvement/tests/test-reflect-wiring.sh`:

```bash
#!/usr/bin/env bash
# Regression guard: keeps config/prompt.md and config/categories.md in sync
# with session-reflect's actual artifact schema and default path. Does NOT
# run the daily-review agent — that costs a real Opus call. See the manual
# dry-run runbook in this plan / prompt.md's own comments for that.
set -euo pipefail

HERE="$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd)"
RSI_DIR="$(cd -- "$HERE/.." && pwd)"
WORKTREE="$(cd -- "$RSI_DIR/.." && pwd)"

PROMPT="$RSI_DIR/config/prompt.md"
CATEGORIES="$RSI_DIR/config/categories.md"
REFLECT_LIB="$WORKTREE/skills/session-reflect/lib.sh"

fail() { echo "FAIL: $*" >&2; exit 1; }

[[ -f "$PROMPT" ]]     || fail "prompt.md not found at $PROMPT"
[[ -f "$CATEGORIES" ]] || fail "categories.md not found at $CATEGORIES"
[[ -f "$REFLECT_LIB" ]] || fail "session-reflect lib.sh not found at $REFLECT_LIB"

for field in patterns discoveries turning_points digressions obstacles_to_autonomy; do
  grep -qF "$field" "$PROMPT"     || fail "prompt.md missing schema field: $field"
  grep -qF "$field" "$CATEGORIES" || fail "categories.md missing schema field mapping: $field"
done

grep -qF 'REFLECT_ROOT:=$HOME/.claude/reflections' "$REFLECT_LIB" \
  || fail "lib.sh default REFLECT_ROOT changed — update prompt.md's hardcoded ~/.claude/reflections path"
grep -qF '~/.claude/reflections/sessions' "$PROMPT" \
  || fail "prompt.md no longer references ~/.claude/reflections/sessions"

echo "PASS"
```
