> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

```bash
#!/usr/bin/env bash
# collect-reflections.sh — condenses session-reflect artifacts from the last
# LOOKBACK_HOURS into a single JSON digest for the RSI daily-review agent.
# Each artifact already carries session_id/source_transcript/generated_at/
# patterns/discoveries/turning_points/digressions/obstacles_to_autonomy (see
# skills/session-reflect/README.md schema) — this script only selects,
# dedupes per session, and sorts; it never re-shapes the artifact JSON.
#
# Usage: collect-reflections.sh
# Env:
#   REFLECT_ROOT    (default: $HOME/.claude/reflections)
#   PROJECTS_DIR    (default: $HOME/.claude/projects)
#   LOOKBACK_HOURS  (default: 24)
#
# Output (stdout): {"reflected": [...], "unreflected_transcripts": [...]}
set -euo pipefail

: "${REFLECT_ROOT:=$HOME/.claude/reflections}"
: "${PROJECTS_DIR:=$HOME/.claude/projects}"
: "${LOOKBACK_HOURS:=24}"

LOOKBACK_MIN=$(( LOOKBACK_HOURS * 60 ))

# --- reflected: final.json in-window, else newest in-window checkpoint when
#     no final.json exists at all (session still open at review time) -------
reflected_files=()
if [[ -d "$REFLECT_ROOT/sessions" ]]; then
  while IFS= read -r f; do
    [[ -n "$f" ]] && reflected_files+=("$f")
  done < <(find "$REFLECT_ROOT/sessions" -type f -name 'final.json' -mmin "-$LOOKBACK_MIN" 2>/dev/null)

  while IFS= read -r cp_dir; do
    [[ -n "$cp_dir" ]] || continue
    session_dir="$(dirname -- "$cp_dir")"
    # A final.json (any age) means this session concluded — checkpoints are
    # superseded either way (either already captured above, or the session
    # concluded outside the window and isn't relevant today).
    [[ -f "$session_dir/final.json" ]] && continue
    newest_cp="$(find "$cp_dir" -maxdepth 1 -type f -name '*.json' -mmin "-$LOOKBACK_MIN" 2>/dev/null | sort | tail -1)"
    [[ -n "$newest_cp" ]] && reflected_files+=("$newest_cp")
  done < <(find "$REFLECT_ROOT/sessions" -type d -name 'checkpoints' 2>/dev/null)
fi

reflected_json='[]'
if (( ${#reflected_files[@]} > 0 )); then
  reflected_json="$(jq -cs 'sort_by(.generated_at)' "${reflected_files[@]}")"
fi

# --- unreflected_transcripts: raw jsonl modified in-window, not under
#     subagents/, with no final.json and no in-window checkpoint on disk ---
unreflected=()
if [[ -d "$PROJECTS_DIR" ]]; then
  while IFS= read -r tp; do
    [[ -n "$tp" ]] || continue
    case "$tp" in
      */subagents/*) continue ;;
    esac
    sid="$(basename -- "$tp" .jsonl)"
    if [[ -f "$REFLECT_ROOT/sessions/$sid/final.json" ]]; then
      continue
    fi
    if find "$REFLECT_ROOT/sessions/$sid/checkpoints" -maxdepth 1 -type f -name '*.json' -mmin "-$LOOKBACK_MIN" 2>/dev/null | grep -q .; then
      continue
    fi
    unreflected+=("$tp")
  done < <(find "$PROJECTS_DIR" -maxdepth 2 -type f -name '*.jsonl' -mmin "-$LOOKBACK_MIN" 2>/dev/null)
fi

unreflected_json='[]'
if (( ${#unreflected[@]} > 0 )); then
  unreflected_json="$(printf '%s\n' "${unreflected[@]}" | jq -R . | jq -s .)"
fi

jq -n --argjson reflected "$reflected_json" --argjson unreflected "$unreflected_json" \
  '{reflected: $reflected, unreflected_transcripts: $unreflected}'
```

    def _write(self, lines):
        f = tempfile.NamedTemporaryFile(mode="w", suffix=".jsonl", delete=False)
        for line in lines:
            f.write(json.dumps(line) + "\n")
        f.close()
        self.addCleanup(os.unlink, f.name)
        return f.name

    def test_counts_user_messages_and_tracks_latest_usage(self):
        path = self._write([

"""Shared context-window fill detection.

Extracted 2026-08-17 from context-baggage.py so context-baggage.py
(interactive 70% advisory nudge) and self-compact's hooks (headless 30%
autonomous trigger) share one model-detection heuristic instead of two
copies drifting apart. A stale copy of ONE_M_MODEL_PREFIXES is exactly how
context-baggage.py once reported 89% full during an 18%-full 1M-window
session — see that file's own git history / comments.
"""
import json
import os

BASE_MAX = 200_000
ONE_M = 1_000_000

# Claude Code model IDs that run at 1M context by default. Prefixes, so
# dated variants (claude-opus-4-1-20250805) match too.
ONE_M_MODEL_PREFIXES = (
    "claude-opus-4-",
    "claude-sonnet-4-",
    "claude-opus-5",
    "claude-sonnet-5",
)
# Explicit 1M marker in the model ID, e.g. `claude-opus-5[1m]`. Checked
# before the prefix list so it keeps working across model generations
# without another edit here.
ONE_M_MARKER = "[1m]"


def detect_max_tokens(model, observed_max, context_max_env=None):
    """Resolve the effective context window size in tokens.

    Priority: explicit override > [1m] marker in the model id > known
    1M-capable model prefix > observed usage already over 200k > default 200k.
    """
    if context_max_env:
        try:
            return int(context_max_env)
        except ValueError:
            pass
    if model:
        if ONE_M_MARKER in model.lower():
            return ONE_M
        if any(model.startswith(p) for p in ONE_M_MODEL_PREFIXES):
            return ONE_M
    if observed_max > BASE_MAX:
        return ONE_M
    return BASE_MAX


def parse_transcript_usage(transcript_path):
    """Scan a Claude Code transcript JSONL for the latest usage snapshot.

    Returns {user_msg_count, last_usage, last_model, observed_max}.
    `last_usage` is None if no assistant turn carried a usage block yet.
    Malformed lines are skipped; a missing file raises OSError to the caller.
    """
    user_msg_count = 0
    last_usage = None
    last_model = None
    observed_max = 0

    with open(transcript_path, "r", errors="replace") as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
            try:
                obj = json.loads(line)
            except json.JSONDecodeError:
                continue

            obj_type = obj.get("type")
            if obj_type == "user":
                user_msg_count += 1
            elif obj_type == "assistant":
                msg = obj.get("message", {})
                model = msg.get("model")
                if model and model != "<synthetic>":
                    last_model = model
                usage = msg.get("usage")
                if usage:
                    last_usage = usage
                    total = (
                        usage.get("input_tokens", 0)
                        + usage.get("cache_creation_input_tokens", 0)
                        + usage.get("cache_read_input_tokens", 0)
                    )
                    if total > observed_max:
                        observed_max = total

    return {
        "user_msg_count": user_msg_count,
        "last_usage": last_usage,
        "last_model": last_model,
        "observed_max": observed_max,
    }


def fill_fraction(transcript_path):
    """Compute context fill for a transcript.

    Returns None if the file is missing. Returns
    {fill_pct, total_tokens, max_tokens, user_msg_count, last_model} otherwise
    (falls back to a file-size estimate if no assistant usage exists yet).
    """
    if not os.path.exists(transcript_path):
        return None
    scanned = parse_transcript_usage(transcript_path)
    max_tokens = detect_max_tokens(
        scanned["last_model"], scanned["observed_max"], os.environ.get("CLAUDE_CONTEXT_MAX")
    )
    last_usage = scanned["last_usage"]
    if last_usage:
        total_tokens = (
            last_usage.get("input_tokens", 0)
            + last_usage.get("cache_creation_input_tokens", 0)
            + last_usage.get("cache_read_input_tokens", 0)
        )
        fill_pct = total_tokens / max_tokens
    else:
        try:
            file_size = os.path.getsize(transcript_path)
        except OSError:
            return None
        total_tokens = file_size // 4
        fill_pct = file_size / (max_tokens * 4)

    return {
        "fill_pct": fill_pct,
        "total_tokens": total_tokens,
        "max_tokens": max_tokens,
        "user_msg_count": scanned["user_msg_count"],
        "last_model": scanned["last_model"],
    }
```

#!/usr/bin/env bash
# self-compact-loop.sh — headless supervisor that reruns `claude -p` as a
# fresh process each iteration instead of growing one long-lived context.
# Composes with orchestrate: each iteration reads tasks/mission.md, does a
# bounded slice of work, refreshes tasks/mission.md, and ends its turn
# BEFORE context balloons (nudged by hooks/context-nudge.sh at the armed
# threshold). The next fresh `claude -p` process picks up where mission.md
# left off — a real context reset (new process, no --resume) rather than an
# in-place /compact.
#
# Usage:
#   self-compact-loop.sh --cwd <dir> --prompt "<initial task prompt>" \
#     --completion-promise "<sigil sentence>" \
#     [--threshold 0.30] [--max-iterations 10] [--model claude-opus-5]
#
# Safety: refuses to arm against $HOME, $HOME/.claude, or $HOME/Repos bare
# (same worktree-isolation boundary as orchestrate's ralph-loop Phase 0 —
# see skills/orchestrate/SKILL.md). Writes .claude/self-compact.local.md in
# <dir>; delete that file, or touch .claude/self-compact.disable, to cancel
# between iterations.
set -euo pipefail
umask 077

if [[ "$(uname -s)" != "Linux" ]]; then
  echo "self-compact-loop: Linux only (uses GNU date/mktemp)" >&2
  exit 2
fi

TARGET_CWD=""
PROMPT=""
COMPLETION_PROMISE=""
THRESHOLD="0.30"
MAX_ITERATIONS="10"
MODEL=""

while [[ $# -gt 0 ]]; do
  case "$1" in
    --cwd) TARGET_CWD="$2"; shift 2 ;;
    --prompt) PROMPT="$2"; shift 2 ;;
    --completion-promise) COMPLETION_PROMISE="$2"; shift 2 ;;
    --threshold) THRESHOLD="$2"; shift 2 ;;
    --max-iterations) MAX_ITERATIONS="$2"; shift 2 ;;
    --model) MODEL="$2"; shift 2 ;;
    *) echo "self-compact-loop: unknown arg '$1'" >&2; exit 2 ;;
  esac
done

[[ -n "$TARGET_CWD" ]] || { echo "REFUSE: --cwd is required"; exit 1; }
[[ -n "$PROMPT" ]] || { echo "REFUSE: --prompt is required"; exit 1; }
[[ -n "$COMPLETION_PROMISE" ]] || { echo "REFUSE: --completion-promise is required (no placeholder — a promise that never matches only stops at max-iterations)"; exit 1; }
case "$COMPLETION_PROMISE" in
  *'"'*|*'$'*|*'`'*|*'\'*) echo 'REFUSE: --completion-promise must not contain " $ ` or \'; exit 1 ;;
esac

TARGET_CWD="$(cd -- "$TARGET_CWD" && pwd)"
case "$TARGET_CWD" in
  "$HOME"|"$HOME/.claude"|"$HOME/Repos")
    echo "REFUSE: arm only against a dedicated worktree/project dir, not $TARGET_CWD"; exit 1 ;;
esac
[[ -e "$TARGET_CWD/.git" ]] || { echo "REFUSE: $TARGET_CWD is not a repo/worktree root"; exit 1; }

if ! [[ "$THRESHOLD" =~ ^0?\.[0-9]+$ ]]; then
  echo "REFUSE: --threshold must be a decimal between 0 and 1 (got: $THRESHOLD)"; exit 1
fi
if ! [[ "$MAX_ITERATIONS" =~ ^[0-9]+$ ]] || (( MAX_ITERATIONS < 1 )); then
  echo "REFUSE: --max-iterations must be a positive integer (got: $MAX_ITERATIONS)"; exit 1
fi

STATE="$TARGET_CWD/.claude/self-compact.local.md"
DISABLE_FLAG="$TARGET_CWD/.claude/self-compact.disable"
LOG_DIR="$TARGET_CWD/.claude/self-compact-logs"
mkdir -p "$TARGET_CWD/.claude" "$LOG_DIR"

now_iso() { date -u +"%Y-%m-%dT%H:%M:%SZ"; }
STARTED_AT="$(now_iso)"

write_state() {
  local iter="$1"
  cat > "$STATE" <<EOF
---
active: true
iteration: $iter
threshold: $THRESHOLD
max_iterations: $MAX_ITERATIONS
completion_promise: "$COMPLETION_PROMISE"
started_at: "$STARTED_AT"
---
$PROMPT
EOF
}

iteration=1
write_state "$iteration"

MODEL_ARGS=()
[[ -n "$MODEL" ]] && MODEL_ARGS=(--model "$MODEL")

CONTINUE_PROMPT="Read tasks/mission.md, tasks/progress.md (if present), and tasks/session-constraints.md (if present) in this directory, then continue from where they left off (empty/missing mission.md = start at the top of the original brief below). Orchestrate via subagents where the orchestrate skill applies; do not implement inline for anything you'd branch for. If every acceptance criterion in tasks/mission.md is complete and the verifier is green, respond with ONLY: <promise>${COMPLETION_PROMISE}</promise> and nothing else. Otherwise keep working; before you'd naturally end this turn, refresh tasks/mission.md (done / next / blocked / open questions) so a fresh process can resume.

Original brief:
$PROMPT"

result="unset"
while (( iteration <= MAX_ITERATIONS )); do
  if [[ -f "$DISABLE_FLAG" ]]; then
    echo "self-compact-loop: disabled via $DISABLE_FLAG, stopping at iteration $iteration"
    result="disabled"
    break
  fi
  if [[ ! -f "$STATE" ]]; then
    echo "self-compact-loop: state file removed, treating as cancel"
    result="cancelled"
    break
  fi

  turn_prompt="$PROMPT"
  (( iteration > 1 )) && turn_prompt="$CONTINUE_PROMPT"

  echo "self-compact-loop: iteration $iteration/$MAX_ITERATIONS (cwd=$TARGET_CWD)"
  out_file="$LOG_DIR/iter-$(printf '%03d' "$iteration").json"
  set +e
  (cd "$TARGET_CWD" && claude -p "${MODEL_ARGS[@]}" --output-format json <<<"$turn_prompt" > "$out_file")
  rc=$?
  set -e
  if (( rc != 0 )); then
    echo "self-compact-loop: claude exited $rc on iteration $iteration (see $out_file)" >&2
  fi

  reply="$(jq -r '.result // empty' "$out_file" 2>/dev/null || true)"
  if [[ "$reply" == *"<promise>${COMPLETION_PROMISE}</promise>"* ]]; then
    echo "self-compact-loop: completion sigil detected at iteration $iteration"
    result="complete"
    break
  fi

  iteration=$(( iteration + 1 ))
  write_state "$iteration"
done

rm -f -- "$STATE"

if [[ "$result" == "unset" ]]; then
  result="max_iterations"
  pending="$TARGET_CWD/pending_for_human.md"
  [[ -f "$pending" ]] || printf '%s\n' "# pending_for_human" "" "Blockers the agent can't clear itself. Format per global CLAUDE.md." > "$pending"
  {
    echo ""
    echo "## $(date -u +%Y-%m-%d): self-compact-loop hit max-iterations ($MAX_ITERATIONS) without the completion sigil"
    echo "**Why blocked**: loop ran $MAX_ITERATIONS iterations against \"$COMPLETION_PROMISE\" and never emitted it"
    echo "**Steps for human**:"
    echo "1. Read $TARGET_CWD/tasks/mission.md for current state"
    echo "2. Either raise --max-iterations and rearm, or take over manually"
    echo "**Everything else done**: see tasks/mission.md and tasks/progress.md in $TARGET_CWD"
  } >> "$pending"
fi

echo "self-compact-loop: stopped (result=$result, iterations=$iteration)"
```

# Self-Compact

Same problem orchestrate's ralph-loop solves (keep an autonomous mission
alive across turns) with a different mechanism: instead of one long-lived
session that eventually needs Claude Code's own lossy `/compact` (or
several — see `recursive-self-improvement/proposals/2026-08-02-repeat-compact-in-session.md`),
`self-compact-loop.sh` restarts `claude -p` as a **brand-new process**
roughly every 30% of the context window, using `tasks/mission.md` as the
sole cross-process memory. A fresh process is a real context reset — no
`--resume`, no accumulated drift — while `mission.md` (curated by the agent
itself) is denser and more reliable than an LLM-summarized compact.

## When to use this instead of plain ralph-loop

- Mission is long enough to blow through several compactions in one
  ralph-loop context.
- Otherwise, prefer ralph-loop alone — same-session cache reuse
  (`--resume --fork-session`, ~77% hit empirically per
  `skills/session-reflect/README.md`) is cheaper per-turn than paying a
  fresh cache_write every ~30%.

## How it fits together

1. `self-compact-loop.sh` arms `.claude/self-compact.local.md` (iteration,
   threshold, max-iterations, completion promise — same discipline as
   ralph-loop's state file) and runs `claude -p` in a loop, one fresh
   process per iteration.
2. `hooks/context-nudge.sh` (PreToolUse) watches context fill via
   `lib/context_fill.py` and, once armed + over threshold, injects a
   throttled reminder to wrap up, refresh `tasks/mission.md`, and end the
   turn — the same `tasks/mission.md` schema session-reflect's mission mode
   uses (`skills/session-reflect/prompts/mission.md`).
3. `hooks/safety-net.sh` (Stop) is the backstop: if the agent ignored the
   nudge, it synchronously calls `reflect.sh mission` before the process
   exits, so the next iteration never resumes blind.
4. The process exiting IS the reset. `self-compact-loop.sh` immediately
   launches the next iteration with a prompt telling it to read
   `tasks/mission.md` and continue, or emit `<promise>...</promise>` if
   done — same sigil convention as ralph-loop.
5. Every iteration is a normal Claude Code session, so the existing
   `PreCompact`/`SessionEnd` session-reflect hooks fire on it exactly like
   any other session — each self-compact iteration produces its own
   `~/.claude/reflections/sessions/<sid>/final.json`. This is what feeds
   the RSI daily-review pipeline
   (`recursive-self-improvement/scripts/collect-reflections.sh`) denser,
   more frequent signal than one long interactive session would.
6. `skills/orchestrate/hooks/compact-reinject.sh` recognizes
   `.claude/self-compact.local.md` too, so if a single iteration still
   grows enough to hit Claude Code's own native compaction before it wraps
   up, the doctrine survives that as well.

## Arming

Run from a dedicated worktree/project root (same isolation boundary as
ralph-loop — never bare `$HOME`, `$HOME/.claude`, or `$HOME/Repos`):

```bash

  --cwd "$(pwd)" \
  --prompt "Autonomous mission: <the brief>. Orchestrate via subagents; do not implement inline." \
  --completion-promise "All acceptance criteria in tasks/mission.md are implemented, the verifier is green, and a fresh-context reviewer confirmed the diff." \
  --threshold 0.30 \
  --max-iterations 10
```

Treat `--completion-promise` and the dangerous-ops manifest the same way
orchestrate's Phase 0 does — this script does not reinvent that ritual; use
it as the loop engine INSIDE Phase 0, not instead of it. Cancel by removing
`.claude/self-compact.local.md`, or pause between iterations by touching
`.claude/self-compact.disable`.

## Cost note

A fresh process pays a cache_write on its first turn (new prefix: CLAUDE.md
+ mission.md + whatever it reads), same as an in-place `/compact` would —
this is cost-comparable, not cost-worse (see `context-baggage.py`'s own
cache-economics comments). The win is quality: mission.md is a curated
handoff the agent wrote for itself, not a lossy LLM summary.

## Red flags

- Arming against a shared repo dir instead of a dedicated worktree.
- `--completion-promise` left as a template placeholder — it will never
  match, and the loop only ends at max-iterations.
- Threshold set so low the agent never gets a full atomic step done before
  the next nudge (thrashing) — 0.30 is a starting point, not a law; raise
  it if iterations keep ending on half-finished steps.
- Using this for ordinary interactive sessions — a human mid-conversation
  does not want their session silently ended. `context-baggage.py`'s
  advisory nudge is the interactive-session tool; this is the headless one.
