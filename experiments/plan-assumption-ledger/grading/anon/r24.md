# RSI-Reflect and Self-Compact Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship two independent-but-complementary packages. **rsi-reflect** rewires the recursive-self-improvement daily-review prompt to read `session-reflect`'s cheap, structured `final.json` artifacts as its primary signal instead of raw transcripts. **self-compact** adds a proactive, context-fill-triggered `tasks/mission.md` refresh for autonomous (ralph-loop-armed) runs, so that whenever this session's context actually resets — by any means — the handoff is never stale.

**Architecture:** Both packages are thin layers over infrastructure that already ships in this repo: `skills/session-reflect/reflect.sh`'s `mission` mode (writes `tasks/mission.md`, ≤60s budget, already used by the idle-handoff timer and the 2nd-in-session-compact defence), and `skills/orchestrate/hooks/compact-reinject.sh` (already re-injects "re-read `tasks/mission.md`" on every `SessionStart(startup|compact|clear)`). rsi-reflect only touches prompt/config text (`recursive-self-improvement/config/*.md`) plus one regression test. self-compact adds one new UserPromptSubmit hook (`skills/self-compact/hooks/context-self-compact.py`), gated to fire only when `.claude/ralph-loop.local.md` is armed in the session's cwd — it never changes behavior for ordinary interactive sessions, which keep today's `context-baggage.py` ask-the-user nudge unchanged. Neither package invents a way to force Claude Code to compact/clear context early — no such hook-triggerable API exists; self-compact's contribution is making sure the handoff artifact is fresh *whenever* a reset naturally happens (native auto-compact, user `/compact`/`/clear`, or a ralph-loop iteration boundary), not moving the reset earlier.

**Tech Stack:** bash (`set -euo pipefail`, GNU tools — matches `session-reflect`'s existing Linux-only convention), Python 3.10+ stdlib only (no pytest on this machine — plain-assert test runners, matching `wellbeing/tests/` and `permission-ledger/tests/` conventions), Claude Code hooks (`UserPromptSubmit`, existing `SessionStart(compact|clear)` reinjection), `jq`.

#!/usr/bin/env python3
"""Shared context-fill-percentage detection for Claude Code hooks.

Single source of truth for turning a transcript JSONL + model id into a
0.0-1.0 context-window fill fraction. Two consumers (context-baggage.py's
interactive nudge, self-compact's autonomous mission.md trigger) import
this rather than each re-deriving max-token detection — a stale copy is
how context-baggage.py once reported 89% full during a session that was
at 18% of a 1M window (every reading was fullness-of-200k).
"""
from __future__ import annotations

import json
import os

BASE_MAX = 200_000
ONE_M = 1_000_000

# Claude Code model IDs that run at 1M context by default. Prefixes, so
# dated variants (claude-opus-4-1-20250805) match too.
ONE_M_MODEL_PREFIXES = (
    "claude-opus-4-",
    "claude-sonnet-4-",
    "claude-opus-5",
    "claude-sonnet-5",
)

# Explicit 1M marker in the model ID, e.g. `claude-opus-5[1m]`. Checked
# before the prefix list so it keeps working across model generations
# without another edit here.
ONE_M_MARKER = "[1m]"


def detect_max_tokens(model: str | None, observed_max: int) -> int:
    """Context window detection, in priority order:
    1. CLAUDE_CONTEXT_MAX env var (explicit override, in tokens)
    2. Model ID prefix / [1m] marker
    3. Observed usage — if any assistant turn exceeded 200k tokens, the
       session is 1M regardless of model name
    4. Default 200k
    """
    override = os.environ.get("CLAUDE_CONTEXT_MAX")
    if override:
        try:
            return int(override)
        except ValueError:
            pass
    if model:
        if ONE_M_MARKER in model.lower():
            return ONE_M
        if any(model.startswith(p) for p in ONE_M_MODEL_PREFIXES):
            return ONE_M
    if observed_max > BASE_MAX:
        return ONE_M
    return BASE_MAX


def scan_transcript(transcript_path: str) -> dict:
    """Scan a transcript JSONL once; return raw signal for fill_percentage."""
    user_msg_count = 0
    last_usage = None
    last_model = None
    observed_max = 0

    with open(transcript_path, "r", errors="replace") as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
            try:
                obj = json.loads(line)
            except json.JSONDecodeError:
                continue

            obj_type = obj.get("type")
            if obj_type == "user":
                user_msg_count += 1
            elif obj_type == "assistant":
                msg = obj.get("message", {})
                model = msg.get("model")
                if model and model != "<synthetic>":
                    last_model = model
                usage = msg.get("usage")
                if usage:
                    last_usage = usage
                    total = (
                        usage.get("input_tokens", 0)
                        + usage.get("cache_creation_input_tokens", 0)
                        + usage.get("cache_read_input_tokens", 0)
                    )
                    if total > observed_max:
                        observed_max = total

    return {
        "user_msg_count": user_msg_count,
        "last_usage": last_usage,
        "last_model": last_model,
        "observed_max": observed_max,
        "file_size": os.path.getsize(transcript_path),
    }


def fill_percentage(scan: dict) -> float:
    """Fraction of the detected context window currently filled."""
    max_tokens = detect_max_tokens(scan["last_model"], scan["observed_max"])
    last_usage = scan["last_usage"]
    if last_usage:
        total_tokens = (
            last_usage.get("input_tokens", 0)
            + last_usage.get("cache_creation_input_tokens", 0)
            + last_usage.get("cache_read_input_tokens", 0)
        )
        return total_tokens / max_tokens
    return scan["file_size"] / (max_tokens * 4)
EOF

UserPromptSubmit hook: warns when context is over THRESHOLD with potentially
stale/off-topic content. Fires every MESSAGE_INTERVAL user messages once
threshold is met.

Context window + fill-percentage detection lives in context_fill.py (shared

for the detection priority order.

import os
import sys

# Raised from 0.25 -> 0.70 on 2026-08-08 after measuring 95.5% cache-hit
# ratio across 7 days / $3,073 spend (probes/analyze_sessions.py). At that
# hit ratio, holding baggage is cheap and resetting is expensive

# a fresh session starts to pay off, not on any drift.
THRESHOLD = 0.70
MESSAGE_INTERVAL = 5

    try:
        data = json.load(sys.stdin)
    except Exception:
        sys.exit(0)

    if not transcript_path or not os.path.exists(transcript_path):

        sys.exit(0)

    max_tokens = detect_max_tokens(scan["last_model"], scan["observed_max"])

    message = (

#!/usr/bin/env python3
"""
UserPromptSubmit hook: proactive context-fill-triggered mission.md refresh
for AUTONOMOUS runs only (gated on .claude/ralph-loop.local.md in cwd).

Interactive sessions keep context-baggage.py's existing ask-the-user nudge
unchanged. This hook targets the case that nudge can't help: an unattended
ralph-loop run with nobody present to answer "which of 3 options?". When
fill crosses SELF_COMPACT_THRESHOLD, it deterministically writes
tasks/mission.md via reflect.sh's `mission` mode (the same mechanism
idle-handoff.sh and the 2nd-compact defence already use) so that whenever
this session's context actually resets — Claude Code's own auto-compact, a
user /compact, or the ralph loop's own iteration boundary — the existing
SessionStart(compact|clear) reinject hook
(skills/orchestrate/hooks/compact-reinject.sh) has a fresh mission.md to
hand the resumed session.

This hook does not and cannot force compaction early: Claude Code exposes
no hook-triggerable compact/clear API. It only guarantees the handoff
artifact is never stale when a reset does happen.
"""
import json
import os
import re
import subprocess
import sys
import time
from pathlib import Path

sys.path.insert(0, str(Path.home() / ".claude"))
from context_fill import scan_transcript, fill_percentage  # noqa: E402

THRESHOLD = float(os.environ.get("SELF_COMPACT_THRESHOLD", "0.70"))
COOLDOWN_SECONDS = int(os.environ.get("SELF_COMPACT_COOLDOWN_SECONDS", str(20 * 60)))
REFLECT_ROOT = Path(os.environ.get("REFLECT_ROOT", str(Path.home() / ".claude" / "reflections")))
REFLECT_SH = Path(os.environ.get(
    "SELF_COMPACT_REFLECT_SH",
    str(Path.home() / ".claude" / "skills" / "session-reflect" / "reflect.sh"),
))
STATE_DIR = REFLECT_ROOT / "self-compact"

_SID_RE = re.compile(r"^[A-Za-z0-9._-]{1,128}$")


def valid_sid(s: str) -> bool:
    return bool(s) and bool(_SID_RE.match(s)) and not s.startswith(".")


def autonomous_run_armed(cwd: str) -> bool:
    return bool(cwd) and (Path(cwd) / ".claude" / "ralph-loop.local.md").is_file()


def cooldown_elapsed(sid: str) -> bool:
    marker = STATE_DIR / f"{sid}.last"
    if not marker.exists():
        return True
    try:
        last = float(marker.read_text().strip())
    except (ValueError, OSError):
        return True
    return (time.time() - last) >= COOLDOWN_SECONDS


def touch_marker(sid: str) -> None:
    STATE_DIR.mkdir(parents=True, exist_ok=True)
    (STATE_DIR / f"{sid}.last").write_text(str(time.time()))


def write_mission(sid: str, transcript_path: str, cwd: str) -> bool:
    if not REFLECT_SH.is_file():
        return False
    payload = json.dumps({
        "session_id": sid,
        "transcript_path": transcript_path,
        "hook_event_name": "SelfCompact",
        "cwd": cwd,
    })
    env = dict(os.environ)
    env.pop("MODE", None)
    try:
        result = subprocess.run(
            ["timeout", "90", "bash", str(REFLECT_SH), "mission"],
            input=payload,
            capture_output=True,
            text=True,
            env=env,
            timeout=95,
        )
    except (OSError, subprocess.TimeoutExpired):
        return False
    return result.returncode == 0


def main():
    try:
        data = json.load(sys.stdin)
    except Exception:
        sys.exit(0)

    sid = data.get("session_id", "")
    transcript_path = data.get("transcript_path", "")
    cwd = data.get("cwd", "")
    if not valid_sid(sid) or not transcript_path or not os.path.exists(transcript_path):
        sys.exit(0)

    if not autonomous_run_armed(cwd):
        sys.exit(0)

    if not cooldown_elapsed(sid):
        sys.exit(0)

    scan = scan_transcript(transcript_path)
    fill_pct = fill_percentage(scan)
    if fill_pct < THRESHOLD:
        sys.exit(0)

    if not write_mission(sid, transcript_path, cwd):
        sys.exit(0)

    touch_marker(sid)
    pct_display = int(fill_pct * 100)
    message = (
        f"[self-compact] Context at {pct_display}% (autonomous run — "
        f".claude/ralph-loop.local.md armed). tasks/mission.md just "
        "refreshed. No need to ask — keep working. Whenever this "
        "session's context compacts or clears (auto or manual), you "
        "resume from tasks/mission.md automatically."
    )
    print(json.dumps({
        "hookSpecificOutput": {
            "hookEventName": "UserPromptSubmit",
            "additionalContext": message,
        }
    }))


if __name__ == "__main__":
    main()
EOF

# self-compact

A `UserPromptSubmit` hook (`hooks/context-self-compact.py`) that
deterministically refreshes `tasks/mission.md` when an **autonomous**
session's context fill crosses a threshold (default 70% used — roughly
30% remaining of a 1M window), instead of waiting for the reactive
triggers session-reflect already has (2nd-in-session `/compact`,
45-55 min idle).

## Why this exists

Three other triggers already write `tasks/mission.md`:

| Trigger | Where | Fires on |
|---|---|---|
| 2nd+ `/compact` in-session | `skills/session-reflect/reflect.sh` (`precompact` branch) | compact count, not context % |
| Idle 45-55 min | `scripts/idle-handoff.sh` (systemd timer) | wall-clock idle time |
| Context fill (this) | `skills/self-compact/hooks/context-self-compact.py` | context %, during an ACTIVE session |

None of the first two catch a long, unattended, actively-running
autonomous session before its context gets uncomfortably full. This one
does — but only for sessions that opted into autonomy by arming
`ralph-loop` (`.claude/ralph-loop.local.md` present in cwd). Ordinary
interactive sessions keep `context-baggage.py`'s existing ask-the-user
nudge, unchanged.

## What this does NOT do

Claude Code exposes no hook-triggerable API to force `/compact` or
`/clear` early. This hook cannot and does not try to reset context ahead
of schedule. What it guarantees instead: whenever a reset *does* happen
— Claude Code's own native auto-compact, a manual `/compact`/`/clear`, or
a ralph-loop iteration boundary — `tasks/mission.md` is never more than
`SELF_COMPACT_COOLDOWN_SECONDS` (default 20 min) stale, and
`skills/orchestrate/hooks/compact-reinject.sh`'s existing
`SessionStart(startup|compact|clear)` reinjection picks it up

ask a human is provided by the already-armed `ralph-loop` plugin's `Stop`
