# RSI-Reflect Wiring + Autonomous Self-Compact Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** (1) Make the recursive-self-improvement daily-review agent consume session-reflect's cheap structured reflection artifacts instead of always re-parsing raw transcripts. (2) Add an autonomous "self-compact" hook that, at ~30% of a 1M-token context window, writes `tasks/mission.md` and directs Claude to compact and resume the task without asking the user — a fully autonomous escalation below the existing 70% manual nudge.

**Architecture:** Both packages are additive, hook-based, and reuse existing infrastructure rather than building new subsystems. RSI-reflect is a prompt-instruction change plus a regression test tying it to session-reflect's real on-disk layout. Self-compact extracts the existing context-window-detection heuristic into a shared module, adds a new UserPromptSubmit hook that reuses `reflect.sh`'s existing (but currently untested) `mission` mode, and adds a new SessionStart(compact) hook that consumes a one-shot sentinel to force autonomous continuation.

**Tech Stack:** Bash (hooks, `jq`), Python 3 (hooks), `unittest` (Python tests), hand-rolled bash smoke tests matching this repo's existing `tests/smoke.sh` conventions.

**Spec:** No separate spec doc exists; this plan is derived directly from repo archaeology (see Assumptions) plus the user's one-line brief: *"rsi reflect and self-compact... self-compact: claude auto writes mission.md and then resets + picks up autonomously at 30% of 1m context or so."*

## Global Constraints

- Never use `Bash` from inside an LLM-invoked headless agent prompt — `settings.json`'s `permissions.deny` contains a blanket `"Bash"` and deny beats allow (see `permission-ledger/run-evaluate.sh` header comment). All deterministic work must happen in hook/wrapper shell scripts that run outside the model's own tool permissions, or via `Glob`/`Read`/`Grep` which the model can call directly.
- All new hook scripts follow the existing repo convention: guard interactive-only hooks with `[ "${CLAUDE_CODE_ENTRYPOINT:-cli}" = "cli" ] || exit 0;` when registered under `UserPromptSubmit`/`PreToolUse`/`SessionStart` (see any existing entry in `settings.json`).
- Session IDs / paths written into hook-adjacent files must never be trusted into a filesystem path without validation — mirror `is_valid_sid()` from `skills/session-reflect/lib.sh` if a new script ever needs to build a path from an untrusted ID (not needed in this plan since all new file paths are CWD-relative, not session-ID-keyed).
- No proposal-pipeline or crontab changes — `recursive-self-improvement/config/config.json`'s `daily_review: false` switch and the `rsi-daily-review` Nix wrapper (lives in `nixos-config`, a different repo) are explicitly **not** touched by this plan.
- Python hook scripts target the Python already used elsewhere in this repo (3.11+ f-strings, `str | None` unions — see `context-baggage.py`), no new dependencies.

## Assumptions

- **SlashCommand tool for `/compact`.** Claude Code exposes a `SlashCommand` tool that lets the model invoke registered slash commands (including built-ins like `/compact`) as an actual tool call during a turn. This plan's self-compact "reset" step relies on instructing Claude to call it. I could not verify this against the exact installed Claude Code version from repo evidence alone. **Mitigation:** Task 10 adds `"SlashCommand(/compact:*)"` to `permissions.allow` in `settings.json` so the call doesn't stall on an interactive approval prompt (which would defeat "autonomously"); the hook's directive text also includes a textual fallback path (self-write `mission.md`, ask the user to compact) if the model has no such tool available, so the feature degrades to "strong nudge" rather than doing nothing. If, during execution, `SlashCommand` turns out not to exist in the installed version, downgrade Task 8's message to the fallback-only text and drop Task 10 — flag this back to the user rather than silently shipping a broken directive.
- **`compact-reinject.sh` is not reused.** That hook (in `skills/orchestrate/hooks/`) is scoped to ralph-loop/orchestrate doctrine persistence, a distinct heavier system. Self-compact gets its own dedicated `hooks/self-compact-reinject.sh` SessionStart(compact) hook rather than extending `compact-reinject.sh`, to avoid coupling an always-on autonomous feature to an opt-in orchestration skill, and to avoid risking a regression in the already-tested doctrine-reinjection behavior.
- **`context-baggage.py`'s 70% manual nudge stays.** Self-compact triggers earlier (30%) and autonomously, but is not guaranteed to succeed (depends on the SlashCommand assumption above). The 70% nudge remains as a human-visible safety net if self-compact silently fails to reduce context.
- **`REFLECT_SUBPROCESS` sentinel reuse.** `reflect.sh`'s `mission` worker spawns `claude -p --resume ... --tools ""` with `REFLECT_SUBPROCESS=1` injected into that subprocess's env, specifically so nested hook fires no-op (see `reflect.sh` lines 46-108). `self-compact-trigger.py` is itself a `UserPromptSubmit` hook and could in principle be re-invoked inside that nested subprocess. Task 6 has it check the same sentinel defensively, even though it's unconfirmed whether `-p --tools ""` invocations fire `UserPromptSubmit` at all — cheap insurance, matches an established convention in this exact codebase.

# the RSI daily-review agent in prompt.md actually match session-reflect's

REPO_ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
SCRIPT = os.path.join(REPO_ROOT, "context-baggage.py")


def _write_transcript(path, user_count, model, usage_per_assistant_msg):
    with open(path, "w", encoding="utf-8") as fh:
        for i in range(user_count):
            fh.write(json.dumps({"type": "user", "message": {"role": "user", "content": "hi"}}) + "\n")
            fh.write(json.dumps({
                "type": "assistant",
                "message": {
                    "role": "assistant",
                    "model": model,
                    "usage": usage_per_assistant_msg,
                },
            }) + "\n")


def _run_hook(transcript_path, cwd=None, env_extra=None):
    payload = json.dumps({"transcript_path": transcript_path})
    env = dict(os.environ)
    env.pop("CLAUDE_CONTEXT_MAX", None)
    if env_extra:
        env.update(env_extra)
    proc = subprocess.run(
        [sys.executable, SCRIPT],
        input=payload,
        capture_output=True,
        text=True,
        env=env,
    )
    return proc


class TestContextBaggageCharacterization(unittest.TestCase):
    def test_below_threshold_no_output(self):
        with tempfile.TemporaryDirectory() as d:
            tp = os.path.join(d, "t.jsonl")
            # 5 user turns (fires the interval gate), low usage -> well under 70%.
            _write_transcript(tp, 5, "claude-opus-5", {
                "input_tokens": 100, "cache_creation_input_tokens": 0, "cache_read_input_tokens": 0,
            })
            proc = _run_hook(tp)
            self.assertEqual(proc.returncode, 0)
            self.assertEqual(proc.stdout.strip(), "")

            tp = os.path.join(d, "t.jsonl")

            self.assertEqual(proc.returncode, 0)
            out = json.loads(proc.stdout)
            msg = out["hookSpecificOutput"]["additionalContext"]

"""Shared context-window detection + fill-percentage math for
context-baggage.py (70% manual nudge) and self-compact-trigger.py (30%
autonomous trigger).

Kept in one place because the model-detection heuristic already had one
dangerous bug (a stale prefix list silently reported 89% full during a
session that was actually 18% full of a 1M-token window) — two
independently-maintained copies would let that class of bug reappear
without anyone noticing the drift between them.
"""
import json
import os

BASE_MAX = 200_000
ONE_M = 1_000_000

# Claude Code model IDs that run at 1M context by default. Prefixes, so
# dated variants (claude-opus-4-1-20250805) match too.
ONE_M_MODEL_PREFIXES = (
    "claude-opus-4-",
    "claude-sonnet-4-",
    "claude-opus-5",
    "claude-sonnet-5",
)

# Explicit 1M marker in the model ID, e.g. `claude-opus-5[1m]`. Checked
# before the prefix list so it keeps working across model generations
# without another edit here.
ONE_M_MARKER = "[1m]"


def detect_max_tokens(model: str | None, observed_max: int) -> int:
    override = os.environ.get("CLAUDE_CONTEXT_MAX")
    if override:
        try:
            return int(override)
        except ValueError:
            pass
    if model:
        if ONE_M_MARKER in model.lower():
            return ONE_M
        if any(model.startswith(p) for p in ONE_M_MODEL_PREFIXES):
            return ONE_M
    if observed_max > BASE_MAX:
        return ONE_M
    return BASE_MAX


def compute_fill_pct(transcript_path: str) -> tuple[float, int, int]:
    """Parse a transcript JSONL and return (fill_pct, max_tokens, user_msg_count).

    fill_pct is always a number: usage-based when the transcript has
    assistant usage data, otherwise a file-size heuristic (bytes / (max*4)).
    """
    user_msg_count = 0
    last_usage = None
    last_model = None
    observed_max = 0

    with open(transcript_path, "r", errors="replace") as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
            try:
                obj = json.loads(line)
            except json.JSONDecodeError:
                continue

            obj_type = obj.get("type")
            if obj_type == "user":
                user_msg_count += 1
            elif obj_type == "assistant":
                msg = obj.get("message", {})
                model = msg.get("model")
                if model and model != "<synthetic>":
                    last_model = model
                usage = msg.get("usage")
                if usage:
                    last_usage = usage
                    total = (
                        usage.get("input_tokens", 0)
                        + usage.get("cache_creation_input_tokens", 0)
                        + usage.get("cache_read_input_tokens", 0)
                    )
                    if total > observed_max:
                        observed_max = total

    max_tokens = detect_max_tokens(last_model, observed_max)

    if last_usage:
        total_tokens = (
            last_usage.get("input_tokens", 0)
            + last_usage.get("cache_creation_input_tokens", 0)
            + last_usage.get("cache_read_input_tokens", 0)
        )
        fill_pct = total_tokens / max_tokens
    else:
        file_size = os.path.getsize(transcript_path)
        fill_pct = file_size / (max_tokens * 4)

    return fill_pct, max_tokens, user_msg_count
```

#!/usr/bin/env python3
"""UserPromptSubmit hook: at ~30% of the model's context window, autonomously
write tasks/mission.md (reusing session-reflect's `mission` mode) and direct
Claude to compact now and resume the task without asking the user.

This fires earlier than context-baggage.py's 70% manual nudge and does not
ask — it acts. The 70% nudge remains as a human-visible fallback in case this
hook's directive is not followed (e.g. no SlashCommand tool available).

Debounced per project directory via tasks/.self-compact-state.json: after a
trigger, it will not fire again until fill_pct either drops back below
THRESHOLD (state cleared) or grows by another RETRIGGER_DELTA (the previous
compact attempt evidently didn't happen).
"""
import json
import os
import subprocess
import sys
import time

from context_window import compute_fill_pct

THRESHOLD = 0.30
RETRIGGER_DELTA = 0.05
MISSION_TIMEOUT_SECONDS = 65  # reflect.sh's mission-mode internal budget is 60s

REFLECT_SH = os.environ.get(
    "SELF_COMPACT_REFLECT_SH",
    os.path.expanduser("~/.claude/skills/session-reflect/reflect.sh"),
)


def _now_iso():
    return time.strftime("%Y-%m-%dT%H:%M:%SZ", time.gmtime())


def decide_action(fill_pct, state, threshold=THRESHOLD, retrigger_delta=RETRIGGER_DELTA, now_iso=None):
    """Pure decision — no I/O. See module docstring for the returned tuple shape."""
    if fill_pct < threshold:
        return ("clear", None) if state is not None else ("noop", None)
    if state is not None and (fill_pct - state.get("fill_pct", 0)) < retrigger_delta:
        return ("skip", None)
    return ("trigger", {"fill_pct": fill_pct, "triggered_at": now_iso or _now_iso()})


def state_path(cwd):
    return os.path.join(cwd, "tasks", ".self-compact-state.json")


def marker_path(cwd):
    return os.path.join(cwd, "tasks", ".self-compact-pending")


def load_state(path):
    try:
        with open(path, encoding="utf-8") as fh:
            return json.load(fh)
    except Exception:
        return None


def write_json_atomic(path, obj):
    os.makedirs(os.path.dirname(path), exist_ok=True)
    tmp = path + ".tmp"
    with open(tmp, "w", encoding="utf-8") as fh:
        json.dump(obj, fh)
    os.replace(tmp, path)


def run_mission_write(payload_json):
    try:
        proc = subprocess.run(
            ["bash", REFLECT_SH, "mission"],
            input=payload_json,
            capture_output=True,
            text=True,
            timeout=MISSION_TIMEOUT_SECONDS,
        )
        return proc.returncode == 0
    except Exception:
        return False


def build_message(fill_pct, max_tokens, mission_written):
    pct_display = int(fill_pct * 100)
    window_display = max_tokens // 1000
    if mission_written:
        return (
            f"[self-compact] Context is {pct_display}% full (window: {window_display}k tokens). "
            "tasks/mission.md has just been written automatically. Per your autonomy contract: "
            "invoke the SlashCommand tool now to run /compact (custom instructions: "
            "'read tasks/mission.md immediately after compacting and continue the task now, "
            "do not ask the user whether to proceed'). Do this as your next action, before "
            "responding to the rest of this message. Do not ask the user first."
        )
    return (
        f"[self-compact] Context is {pct_display}% full (window: {window_display}k tokens). "
        "The automatic tasks/mission.md write failed. Per CLAUDE.md's context-checkpoint rule, "
        "write tasks/mission.md yourself right now (see "
        "skills/session-reflect/prompts/mission.md for the required structure), then invoke "
        "the SlashCommand tool to run /compact and continue without asking the user."
    )


def main():
    # Recursion break: reflect.sh's mission worker spawns a `claude -p ...`
    # subprocess with REFLECT_SUBPROCESS=1 injected into its env specifically
    # so nested hook fires no-op (see reflect.sh's own recursion guard). This
    # hook can in principle be re-invoked inside that subprocess; honor the
    # same sentinel defensively.
    if os.environ.get("REFLECT_SUBPROCESS") == "1":
        sys.exit(0)

    try:
        data = json.load(sys.stdin)
    except Exception:
        sys.exit(0)

    transcript_path = data.get("transcript_path", "")
    cwd = data.get("cwd") or os.getcwd()
    session_id = data.get("session_id", "")
    if not transcript_path or not os.path.exists(transcript_path):
        sys.exit(0)

    fill_pct, max_tokens, user_msg_count = compute_fill_pct(transcript_path)
    if user_msg_count == 0:
        sys.exit(0)

    st_path = state_path(cwd)
    state = load_state(st_path)

    action, new_state = decide_action(fill_pct, state)

    if action in ("noop", "skip"):
        sys.exit(0)

    if action == "clear":
        try:
            os.remove(st_path)
        except OSError:
            pass
        sys.exit(0)

    # action == "trigger"
    write_json_atomic(st_path, new_state)

    payload = json.dumps({
        "session_id": session_id,
        "transcript_path": transcript_path,
        "hook_event_name": "UserPromptSubmit",
        "cwd": cwd,
    })
    mission_written = run_mission_write(payload)

    if mission_written:
        write_json_atomic(marker_path(cwd), new_state)

    message = build_message(fill_pct, max_tokens, mission_written)
    print(json.dumps({"hookSpecificOutput": {"hookEventName": "UserPromptSubmit", "additionalContext": message}}))


if __name__ == "__main__":
    main()
```
