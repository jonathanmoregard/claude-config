# rsi-reflect + self-compact Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the two feature packages the user asked for as one coherent pair: **rsi-reflect** (a proactive, context-usage-threshold-triggered `tasks/mission.md` checkpoint, closing fix #1 of the existing-but-unimplemented RSI proposal) and **self-compact** (the ralph-loop-aware layer on top that keeps an autonomous loop's handoff artifacts fresh as it burns context, so the loop survives compaction and resumes on its own).

**Architecture:** One new Stop hook, `skills/session-reflect/context-checkpoint.sh`, does both jobs from a single context-usage reading per turn. It computes live context usage directly from the session transcript (no dependency on the third-party statusline plugin), and when usage crosses a configurable threshold (default 70% used / 30% remaining, `1_000_000`-token window by default per the user's stated setup), it synchronously refreshes `tasks/mission.md` via the *existing* `reflect.sh mission` mode. If a ralph-loop is armed in the cwd (`.claude/ralph-loop.local.md` present), it additionally appends a dated checkpoint note to `tasks/progress.md` — the file every ralph iteration is already required to re-read — and stays completely silent on stdout so it can never race or pollute the ralph plugin's own Stop-hook block/refeed decision. The hook never returns a Stop "decision" itself; it is a pure observer + file-writer, which is what makes it safe to run alongside the ralph-loop plugin's hook without any ordering assumptions. A latent bug in `reflect.sh`'s manifest idempotency (mission-mode calls after the first one in a session are silently dropped) is fixed first, since both packages depend on mission-mode being repeatable within one long session.

**Tech Stack:** bash (GNU coreutils/date/jq, Linux-only, matching `session-reflect`'s existing constraint), Claude Code Stop hooks, the existing `session-reflect` skill (`reflect.sh`, `lib.sh`), the existing `ralph-loop@claude-plugins-official` plugin state file convention, `settings.json` hook wiring.

**Spec:** `recursive-self-improvement/proposals/2026-08-02-repeat-compact-in-session.md` (fix #1, the proactive-threshold piece, is what this plan implements; fixes #2 and #3 are already shipped — verified by reading `skills/session-reflect/reflect.sh`'s "2nd-compact defence" and `skills/orchestrate/hooks/compact-reinject.sh`).

This already latently affects `idle-handoff.sh` (fires once, then never again for a still-idle session) and would completely defeat Task 3/4's repeat-firing design if left unfixed.

```bash

# --- Context usage percentage from a live transcript -------------------------
# compute_context_usage_percent <transcript_path> <window_size>
# Sums input_tokens + cache_creation_input_tokens + cache_read_input_tokens
# from the MOST RECENT assistant turn's usage object. Claude Code duplicates
# the same usage object across every content-block line of one API turn
# (verified against a real transcript 2026-08-17), so taking the last
# assistant line's usage is correct. Prints an integer 0-100, or empty when
# the percentage cannot be determined. Callers MUST treat empty as "skip" —
# this function never fails loud, matching every other lib.sh helper.
compute_context_usage_percent() {
  local transcript="$1" window="${2:-}"
  [[ -f "$transcript" ]] || { printf ''; return 0; }
  [[ "$window" =~ ^[0-9]+$ ]] && (( window > 0 )) || { printf ''; return 0; }

  local last_lines
  last_lines="$(grep '"role":"assistant"' "$transcript" 2>/dev/null | tail -n 50 || true)"
  [[ -n "$last_lines" ]] || { printf ''; return 0; }

  local used
  used="$(printf '%s\n' "$last_lines" | jq -rs '
    [ .[] | .message.usage? // empty ] | last // empty
    | if . == null or . == "" then empty
      else ((.input_tokens // 0) + (.cache_creation_input_tokens // 0) + (.cache_read_input_tokens // 0))
      end
  ' 2>/dev/null || true)"
  [[ "$used" =~ ^[0-9]+$ ]] || { printf ''; return 0; }

  local pct=$(( used * 100 / window ))
  (( pct > 100 )) && pct=100
  printf '%d' "$pct"
}
```

```bash
#!/usr/bin/env bash
# context-checkpoint.sh — Stop hook. Proactive context-threshold checkpoint.
#
# rsi-reflect: when live context usage crosses SELF_COMPACT_THRESHOLD_PERCENT,
# refreshes tasks/mission.md synchronously (reflect.sh mission mode) instead
# of waiting for the 2nd in-session /compact or 45min of idle time. See
# recursive-self-improvement/proposals/2026-08-02-repeat-compact-in-session.md
# (fix #1).
#
# self-compact: when a ralph-loop is armed in this cwd, additionally appends
# a dated note to tasks/progress.md instead of printing to stdout (Task 4).
#
# Never returns a Stop "decision" — this hook only ever observes and writes
# files. That keeps it inert with respect to any OTHER Stop hook (notably
# the ralph-loop plugin's own block+refeed), so it can never race or clobber
# another hook's stop decision.
set -euo pipefail
umask 077

if [[ "$(uname -s)" != "Linux" ]]; then
  exit 0
fi

SCRIPT_DIR="$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd)"
# shellcheck disable=SC1091
source "$SCRIPT_DIR/lib.sh"

: "${REFLECT_ROOT:=$HOME/.claude/reflections}"
: "${SELF_COMPACT_THRESHOLD_PERCENT:=70}"
: "${SELF_COMPACT_CONTEXT_WINDOW_SIZE:=1000000}"
: "${SELF_COMPACT_MIN_INTERVAL_SECONDS:=600}"

PAYLOAD="$(cat)"
[[ -n "$PAYLOAD" ]] || exit 0

SESSION_ID="$(jq -r '.session_id // empty' <<<"$PAYLOAD" 2>/dev/null || true)"
TRANSCRIPT_PATH="$(jq -r '.transcript_path // empty' <<<"$PAYLOAD" 2>/dev/null || true)"
[[ -n "$SESSION_ID" && -n "$TRANSCRIPT_PATH" ]] || exit 0
is_valid_sid "$SESSION_ID" || exit 0

[[ "$SELF_COMPACT_THRESHOLD_PERCENT" =~ ^[0-9]+$ ]] || exit 0
[[ "$SELF_COMPACT_CONTEXT_WINDOW_SIZE" =~ ^[0-9]+$ ]] || exit 0

PCT="$(compute_context_usage_percent "$TRANSCRIPT_PATH" "$SELF_COMPACT_CONTEXT_WINDOW_SIZE")"
[[ -n "$PCT" ]] || exit 0
(( PCT >= SELF_COMPACT_THRESHOLD_PERCENT )) || exit 0

ensure_reflect_root_writable || exit 0

STATE_DIR="$REFLECT_ROOT/sessions/$SESSION_ID"
STATE_FILE="$STATE_DIR/context-checkpoint-state.json"
mkdir -p "$STATE_DIR" 2>/dev/null || exit 0

NOW_EPOCH="$(date -u +%s)"
LAST_FIRED_EPOCH=0
if [[ -f "$STATE_FILE" ]]; then
  LAST_FIRED_EPOCH="$(jq -r '.last_fired_epoch // 0' "$STATE_FILE" 2>/dev/null || echo 0)"
  [[ "$LAST_FIRED_EPOCH" =~ ^[0-9]+$ ]] || LAST_FIRED_EPOCH=0
fi
(( NOW_EPOCH - LAST_FIRED_EPOCH >= SELF_COMPACT_MIN_INTERVAL_SECONDS )) || exit 0

MISSION_PAYLOAD="$(jq -cn --arg sid "$SESSION_ID" --arg tp "$TRANSCRIPT_PATH" --arg cwd "$PWD" \
  '{session_id:$sid, transcript_path:$tp, hook_event_name:"Stop", cwd:$cwd}')"
printf '%s' "$MISSION_PAYLOAD" | env -u MODE bash "$SCRIPT_DIR/reflect.sh" mission >/dev/null 2>&1 || true

TMP_STATE="$(mktemp -p "$STATE_DIR" ".ctxcp-XXXXXX")"
jq -cn --argjson pct "$PCT" --argjson now "$NOW_EPOCH" \
  '{last_fired_epoch:$now, last_fired_percent:$pct}' > "$TMP_STATE" 2>/dev/null \
  && mv -f "$TMP_STATE" "$STATE_FILE" 2>/dev/null \
  || rm -f "$TMP_STATE" 2>/dev/null || true

printf '[self-compact] Context at %d%% (threshold %d%%). tasks/mission.md just refreshed — consider /compact now, or start a fresh session; the handoff is ready.\n' \
  "$PCT" "$SELF_COMPACT_THRESHOLD_PERCENT"
exit 0
```

## Deliberately out of scope (documented, not silently dropped)

- **Forcing real compaction from a hook.** No supported Claude Code mechanism found; the `ralph-loop` plugin's own Stop hook (the one hook proven to influence session continuation) only blocks-and-refeeds a fixed prompt into the *same* growing context, it never resets anything. Revisit if Anthropic exposes a programmatic compact trigger.
- **Killing and respawning the live `claude` process to force a true zero-context reset.** Technically conceivable (spawn a detached fresh session, no `--resume`, seeded from `tasks/mission.md`) but requires the *old* process to exit cleanly without ralph's own Stop hook independently re-blocking it (a real coordination race against third-party plugin code we don't own), and — for the interactive case — killing a session out from under a human mid-conversation is exactly the kind of hard-to-reverse action this repo's own `CLAUDE.md` says to check with the user about first. Not attempted here.
- **Reading context usage from the third-party `token-optimizer` statusline plugin's `live-fill.json`.** Would be cheaper (Claude Code already computes it) but couples this feature to an external, independently-versioned plugin that may not be installed/enabled, and doesn't fire at all during headless (`-p`) invocations. Self-contained transcript computation was chosen instead.
- **A dedicated `self-compact` skill directory.** The two packages share one hook and one state model; splitting them into separate skill dirs would duplicate transcript-parsing and double the Stop-hook overhead for no benefit. Documented as one feature, in one file, with two clearly-labeled behavior branches.
