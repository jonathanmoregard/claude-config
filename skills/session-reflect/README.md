# session-reflect

Session-scoped self-reflection artifacts for Claude Code, produced from the
`PreCompact`, `SessionEnd`, and `SubagentStop` hooks. Each reflection is
generated by a detached `claude -p --resume --fork-session` subprocess so
session shutdown is never blocked on model latency, and API-side prompt
caching (1 h TTL) keeps token cost bounded (~77 % cache hit at 12 min age,
verified 2026-08-08).

Non-goals: cross-session aggregation, synthesis, retrieval. Those are a
separate later system that reads these artifacts.

## What it produces

For each session (parent or subagent):

```
~/.claude/reflections/sessions/<parent-session-id>/
  checkpoints/
    0001-precompact.json         # one per PreCompact, chronological
    0002-precompact.json
  final.json                     # SessionEnd reflection (incorporates checkpoints)
  manifest.json                  # status, timestamps, source_transcript, usage
  subagents/
    <subagent-session-id>/
      final.json                 # SubagentStop reflection
      manifest.json
      checkpoints/               # rare — subagents usually finish before compaction
```

Every `final.json` and `*-precompact.json` conforms to this schema:

```json
{
  "patterns":              ["..."],
  "discoveries":           ["..."],
  "turning_points":        ["..."],
  "digressions":           ["..."],
  "obstacles_to_autonomy": ["..."],
  "session_id":            "...",
  "parent_session_id":     null,
  "mode":                  "sessionend | precompact | subagentstop",
  "hook_event_name":       "SessionEnd | PreCompact | SubagentStop",
  "generated_at":          "2026-08-08T12:34:56Z",
  "source_transcript":     "/home/.../projects/.../<sid>.jsonl",
  "usage":                 { "cache_read_input_tokens": 55511, ... }
}
```

`manifest.json` mirrors the metadata and adds `status`
(`started | complete | timeout | error | skipped_duplicate`),
`started_at`, `completed_at`, `final_complete`, and (for the terminal
`skipped_duplicate` case) records that a duplicate invocation was seen but
skipped.

## Hook configuration

Add to `~/.claude/settings.json`:

```json
{
  "env": {
    "CLAUDE_CODE_SESSIONEND_HOOKS_TIMEOUT_MS": "90000"
  },
  "hooks": {
    "PreCompact": [
      {
        "hooks": [
          { "type": "command", "command": "bash ~/.claude/skills/session-reflect/reflect.sh precompact" }
        ]
      }
    ],
    "SessionEnd": [
      {
        "hooks": [
          { "type": "command", "command": "bash ~/.claude/skills/session-reflect/reflect.sh sessionend" }
        ]
      }
    ],
    "SubagentStop": [
      {
        "hooks": [
          { "type": "command", "command": "bash ~/.claude/skills/session-reflect/reflect.sh subagentstop" }
        ]
      }
    ]
  }
}
```

The `settings-patch.json` file in this repo root is the reference
snippet; do not apply it blindly.

**Do not use `jq -s '.[0] * .[1]'` to merge.** The `*` operator *replaces*
existing arrays rather than concatenating them, so if you already have any
`PreCompact` / `SessionEnd` / `SubagentStop` hooks configured, that merge
silently drops them. Instead, use an array-concat merge, or manually
append the new entries to the existing arrays. Example append-array merge
is documented inside `settings-patch.json` under `_comment`.

## Environment variables

| Var | Default | Purpose |
|-----|---------|---------|
| `REFLECT_MODEL` | `haiku` | Model alias (or full id) for reflection subprocess. Alias `haiku` resolves to the latest Haiku tier and survives model retirement. Use `sonnet`/`opus` only if you need richer synthesis. |
| `REFLECT_ROOT` | `$HOME/.claude/reflections` | Artifact root. Override for tests. Must be writable. |
| `REFLECT_FORCE` | (unset) | Truthy values (`1`, `true`, `yes`, `on`, case-insensitive) bypass the idempotency guard and re-run even if `final_complete: true`. Any other value = falsy. |
| `REFLECT_LOG_DIR` | `$REFLECT_ROOT/logs` | Worker stdout / stderr logs. |
| `REFLECT_STALE_STARTED_SECONDS` | `600` | If a manifest is stuck at `status=started` older than this many seconds, treat as a crashed prior run and permit re-run. |
| `REFLECT_LIVE_TEST` | (unset) | `1` opts `tests/live.sh` into a real-API smoke. |
| `CLAUDE_PARENT_SESSION_ID` | (unset) | If Claude Code exports this into the SubagentStop env, subagent artifacts nest under the correct parent. Otherwise the dispatcher falls back to scanning sibling transcript JSONLs. Value is validated against `^[A-Za-z0-9._-]{1,128}$`; invalid values are ignored. |
| `_REFLECT_INTERNAL` | (internal) | Sentinel set by the parent dispatcher to gate the `--worker` re-entry path. Do not set manually. |

## Behaviour by hook

| Hook | Blocking? | Timeout | Artifact |
|------|-----------|---------|----------|
| `PreCompact` | Yes (session still alive) | 60 s | `checkpoints/NNNN-precompact.json` |
| `SessionEnd` | No — fire-and-forget detached worker | 90 s wall (worker internal) | `final.json` |
| `SubagentStop` | No — fire-and-forget detached worker | 40 s wall (worker internal) | `subagents/<sid>/final.json` |

Detached workers use `setsid nohup ... </dev/null >log 2>&1 & disown` so
they survive kitty close, `exit`, and the parent Claude Code process
terminating. `SIGKILL`, hard OS shutdown, and crashes remain out of scope
(hooks cannot fire in those cases).

Reflection is idempotent: reruns with the same session id and a
`final_complete: true` manifest exit fast without spawning a new
subprocess, unless `REFLECT_FORCE=1`.

## Inspecting artifacts

```bash
# List all sessions with reflection artifacts
ls -1 ~/.claude/reflections/sessions/

# See the manifest for a specific session
jq . ~/.claude/reflections/sessions/<sid>/manifest.json

# Read the final reflection
jq . ~/.claude/reflections/sessions/<sid>/final.json

# List checkpoint reflections for a long session
ls -1 ~/.claude/reflections/sessions/<sid>/checkpoints/

# Walk parent -> subagent tree
find ~/.claude/reflections/sessions/<parent-sid>/subagents -name final.json
```

## Pruning stale artifacts

Reflection artifacts are tiny (JSON, ~1-5 KB each). They accumulate one
directory per session id, which is fine for months of use. To prune:

```bash
# Delete artifacts older than 90 days
find ~/.claude/reflections/sessions -mindepth 1 -maxdepth 1 -type d \
  -mtime +90 -exec rm -rf {} +

# Delete worker logs older than 14 days
find ~/.claude/reflections/logs -type f -mtime +14 -delete
```

Do not automate deletion until you have an aggregator consuming these
artifacts and know what "safe to delete" means for your workflow.

## Failure modes

- **Missing `session_id` or `transcript_path` in payload.** Writes an
  error record under `sessions/_malformed/` containing only the payload
  SHA-256 and length (no raw body) and exits 0. Never blocks the caller.
- **`session_id` fails safe-charset check (`^[A-Za-z0-9._-]{1,128}$`).**
  Same as above with `reason: "invalid_session_id"`. Rejects path
  traversal (`../evil`, `/abs/path`), spaces, newlines, control chars.
- **Concurrent invocation.** If a second dispatcher can't get the
  per-session `flock`, it records a `skipped_concurrent` marker under
  `<session_dir>/duplicates/` and exits fast without spawning a worker.
- **Duplicate after completion.** If a session's manifest is already
  `final_complete: true`, a fresh invocation records a `skipped_duplicate`
  marker under `<session_dir>/duplicates/` and exits without touching the
  original manifest or artifacts.
- **Stale `started` manifest.** If a manifest sits at `status=started`
  older than `REFLECT_STALE_STARTED_SECONDS` (default 600s), the guard
  treats it as a crashed prior run and permits a fresh run.
- **`claude` subprocess exits non-zero.** Manifest status becomes
  `error` with `subprocess_exit_code`. Stderr in
  `logs/<sid>-<mode>.stderr.log`.
- **Timeout.** Manifest status becomes `timeout`. Compaction proceeds
  either way.
- **Model emits non-JSON.** Manifest status becomes `error` with
  `reason: "unparseable_reflection_json"`. Only the first 200 chars of
  the raw reply are preserved (as `raw_excerpt`); the full body is not
  written to the manifest to avoid leaking potentially sensitive
  reflection content.

## Security

- The reflection subprocess runs with `--tools ""`, disabling the entire
  built-in tool set. Even if a prompt-injection payload smuggled through
  the resumed transcript tries to make the model invoke `Bash`, `Edit`,
  `WebFetch`, etc., the CLI refuses. `--dangerously-skip-permissions`
  is NOT set.
- `session_id` and `parent_session_id` are validated against a safe
  charset before use in any filesystem path.
- The `--worker` re-entry mode requires `_REFLECT_INTERNAL=1` in env;
  external `reflect.sh --worker <mode>` invocations are refused.
- Artifacts are written with `umask 077` (owner-only permissions).

## Tests

```bash
# Offline smoke — uses a stub `claude` on PATH. Zero API cost. Default.
bash tests/smoke.sh

# Live smoke — opt-in. One real Haiku call, ~few thousand tokens.
REFLECT_LIVE_TEST=1 bash tests/live.sh
```

## Empirical basis

Verified 2026-08-08 against the shipped Claude Code build:

- `claude -p --resume <sid> --fork-session --output-format json` against
  a 12-minute-old sibling session returned
  `cache_read_input_tokens: 55,511` vs
  `cache_creation_input_tokens: 16,925` — roughly 77 % of input served
  from cache.
- Transcripts record `cache_creation` under
  `ephemeral_1h_input_tokens`; cache TTL is 1 hour, not the 5-minute
  default originally assumed.
- Transcript JSONL files persist raw tool result bodies (up to 38 KB
  per entry), so the prefix `--resume` replays is byte-identical to
  what the live session sent — prompt caching prefixes match.

See the source spec for details:
`~/.claude/proposals/manual/from 4th of august - rsi token efficiency.md`.
