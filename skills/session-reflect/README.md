# session-reflect

**Requires:** Linux + GNU coreutils (`date -d`, `mktemp` suffix-after-X's,
`stat -c`, `sha256sum`), plus `jq`, `flock`, `timeout`, `setsid`, and the
`claude` CLI (Anthropic Claude Code) on `PATH`. Dispatcher fails fast with
exit 2 on non-Linux.

Session-scoped self-reflection artifacts for Claude Code, produced from the
`PreCompact`, `SessionEnd`, and `SubagentStop` hooks. Each reflection is
generated by a detached `claude -p --resume --fork-session` subprocess so
session shutdown is never blocked on model latency, and API-side prompt
caching (1 h TTL) keeps token cost bounded (~77 % cache hit at 12 min age,
verified 2026-08-08).

Non-goals: cross-session aggregation, synthesis, retrieval. Those are a
separate later system that reads these artifacts.

## What it produces

For each session (parent or subagent):

```
~/.claude/reflections/sessions/<parent-session-id>/
  checkpoints/
    <epoch_ns>-XXXX-precompact.json   # one per PreCompact, chronological
    <epoch_ns>-XXXX-precompact.json
  final.json                     # SessionEnd reflection (incorporates checkpoints)
  manifest.json                  # status, timestamps, source_transcript, usage
  duplicates/                    # side-records of skipped invocations
    <UTC>-<mode>-XXXX.json       #   skipped_duplicate (post-completion re-fire)
    <UTC>-<mode>-conc-XXXX.json  #   skipped_concurrent (flock contention)
  subagents/
    <subagent-session-id>/
      final.json                 # SubagentStop reflection
      manifest.json
      checkpoints/               # rare — subagents usually finish before compaction
      duplicates/                # same shape as parent, subagent-scoped
```

Every `final.json` and `*-precompact.json` conforms to this schema:

```json
{
  "patterns":              ["..."],
  "discoveries":           ["..."],
  "turning_points":        ["..."],
  "digressions":           ["..."],
  "obstacles_to_autonomy": ["..."],
  "session_id":            "...",
  "parent_session_id":     null,
  "mode":                  "sessionend | precompact | subagentstop",
  "hook_event_name":       "SessionEnd | PreCompact | SubagentStop",
  "generated_at":          "2026-08-08T12:34:56Z",
  "source_transcript":     "/home/.../projects/.../<sid>.jsonl",
  "usage":                 { "cache_read_input_tokens": 55511, ... }
}
```

`manifest.json` is a **per-mode state map** (R3.1 fix for cross-mode race):

```json
{
  "session_id":        "...",
  "parent_session_id": null,
  "hook_event_name":   "...",
  "source_transcript": "...",
  "modes": {
    "precompact":   { "status": "complete", "started_at": "...", "completed_at": "...", "final_complete": false, "last_checkpoint_at": "...", "artifact": "...", "usage": {...} },
    "sessionend":   { "status": "complete", "started_at": "...", "completed_at": "...", "final_complete": true,  "artifact": "...", "usage": {...} },
    "subagentstop": { "status": "complete", "started_at": "...", "completed_at": "...", "final_complete": true,  "artifact": "...", "usage": {...} }
  }
}
```

Each mode carries its own `status`
(`started | complete | timeout | error | skipped_duplicate`),
`started_at`, `completed_at`, `final_complete`, and mode-specific extras
(`artifact`, `usage`, `reason`, `raw_excerpt`, `raw_len`, `timeout_seconds`,
`subprocess_exit_code`, `trigger`, `model`). Nesting per-mode is what
prevents PreCompact's transient `started` state from blocking a concurrent
SessionEnd or SubagentStop — each mode's idempotency check reads only
`modes.<mode>`.

The terminal `skipped_duplicate` case is recorded as a side-file under
`duplicates/` rather than mutating the manifest, preserving evidence.

## Hook configuration

Add to `~/.claude/settings.json`:

```json
{
  "env": {
    "CLAUDE_CODE_SESSIONEND_HOOKS_TIMEOUT_MS": "90000"
  },
  "hooks": {
    "PreCompact": [
      {
        "hooks": [
          { "type": "command", "command": "bash ~/.claude/skills/session-reflect/reflect.sh precompact" }
        ]
      }
    ],
    "SessionEnd": [
      {
        "hooks": [
          { "type": "command", "command": "bash ~/.claude/skills/session-reflect/reflect.sh sessionend" }
        ]
      }
    ],
    "SubagentStop": [
      {
        "hooks": [
          { "type": "command", "command": "bash ~/.claude/skills/session-reflect/reflect.sh subagentstop" }
        ]
      }
    ]
  }
}
```

The `settings-patch.json` file in this repo root is the reference
snippet; do not apply it blindly.

**Do not use `jq -s '.[0] * .[1]'` to merge.** The `*` operator *replaces*
existing arrays rather than concatenating them, so if you already have any
`PreCompact` / `SessionEnd` / `SubagentStop` hooks configured, that merge
silently drops them. Instead, use an array-concat merge, or manually
append the new entries to the existing arrays. Example append-array merge
is documented inside `settings-patch.json` under `_comment`.

## Environment variables

| Var | Default | Purpose |
|-----|---------|---------|
| `REFLECT_MODEL` | `haiku` | Model alias (or full id) for reflection subprocess. Alias `haiku` resolves to the latest Haiku tier and survives model retirement. Use `sonnet`/`opus` only if you need richer synthesis. |
| `REFLECT_ROOT` | `$HOME/.claude/reflections` | Artifact root. Override for tests. Must be writable. |
| `REFLECT_FORCE` | (unset) | Truthy values (`1`, `true`, `yes`, `on`, case-insensitive) bypass the idempotency guard and re-run even if `modes.<mode>.final_complete: true`. Any other value = falsy. |
| `REFLECT_LOG_DIR` | `$REFLECT_ROOT/logs` | Worker stdout / stderr logs. |
| `REFLECT_STALE_STARTED_SECONDS` | `600` | If a manifest is stuck at `status=started` older than this many seconds, treat as a crashed prior run: permit re-run, and let the reaper demote it to a terminal `error`. |
| `REFLECT_ASYNC` | (unset) | `mission` mode only. Truthy detaches the worker instead of running it synchronously. Set by the 2nd-compact pre-fire so the mission model call cannot eat the 60 s hook cap. `scripts/idle-handoff.sh` deliberately leaves it unset — it reads `modes.mission.status` right after the call. |
| `REFLECT_NO_SYSTEMD_RUN` | (unset) | Truthy forces the `setsid` fallback spawn instead of `systemd-run --user`. Mostly for tests and hosts where you want the old behaviour. |
| `REFLECT_BUDGET_PRECOMPACT` / `_SESSIONEND` / `_SUBAGENTSTOP` / `_MISSION` | `40` / `90` / `40` / `60` | Per-mode timeout budget in seconds. See "Budgets vs the hook cap". |
| `REFLECT_KILL_GRACE_SECONDS` | `10` | `timeout -k` grace before SIGKILL. Counts against the hook cap. |
| `REFLECT_REAP_MAX_PER_RUN` | `200` | Max manifests the orphan reaper examines per detached-worker run. |
| `REFLECT_MISSION_RETENTION_DAYS` | `30` | Age after which a `tasks/mission.<sid>.md` payload is garbage-collected. |
| `REFLECT_LIVE_TEST` | (unset) | `1` opts `tests/live.sh` into a real-API smoke. |
| `CLAUDE_PARENT_SESSION_ID` | (unset) | If Claude Code exports this into the SubagentStop env, subagent artifacts nest under the correct parent. Otherwise the dispatcher falls back to scanning sibling transcript JSONLs. Value is validated against `^[A-Za-z0-9._-]{1,128}$`; invalid values are ignored. |
| `_REFLECT_INTERNAL` | (internal) | Sentinel set by the parent dispatcher to gate the `--worker` re-entry path. Do not set manually. |

## Behaviour by hook

| Hook | Blocking? | Timeout | Artifact |
|------|-----------|---------|----------|
| `PreCompact` | Yes (session still alive) | 40 s | `checkpoints/<epoch_ns>-XXXX-precompact.json` |
| `SessionEnd` | No — fire-and-forget detached worker | 90 s wall (worker internal) | `final.json` |
| `SubagentStop` | No — fire-and-forget detached worker | 40 s wall (worker internal) | `subagents/<sid>/final.json` |

On the 2nd-and-later `PreCompact` of a session the dispatcher also pre-fires
`mission` mode. That pre-fire is **detached** (`REFLECT_ASYNC=1`): it used to run
synchronously ahead of the precompact worker, which measured 121 s of in-hook
wall time against a 60 s cap.

### Budgets vs the hook cap

Claude Code caps every `command` hook at **60 s and the cap is not
configurable** — the bundled `cli.js` computes `timeout ? q.timeout*1000 : 60000`
and the settings schema clamps `timeout` with `.max(60000)`. When the cap fires
Claude Code kills the hook's process group, so no terminal status is written.
The internal budget must therefore always win:

```
precompact 40 s + kill grace 10 s + reserve 5 s = 55 s worst case  <=  60 s cap
```

`bash reflect.sh --budgets` prints the live arithmetic. Only `precompact` is
synchronous; the detached modes are off the hook clock.

### Detached spawn

Detached workers are handed to `systemd-run --user --collect --no-block`, which
runs them in their **own cgroup**. `setsid nohup … &` escapes SIGHUP and the
controlling terminal but *not* the parent's cgroup: Claude Code exits seconds
after `SessionEnd`, and the cgroup teardown that follows (`KillMode=control-group`
is the systemd default) SIGKILLed the worker before it wrote anything. That was
the source of the orphaned `status:started` manifests — 0-byte
`<sid>-<mode>.worker.stderr.log`, no `.stdout.log`, log mtime == `started_at`.

Transient units inherit no environment, so every var the worker needs is passed
explicitly with `--setenv`, and because a unit cannot inherit fd 9 the per-mode
flock is acquired by the *worker* from `REFLECT_LOCKFILE` rather than inherited.
With no user bus (busless cron, container without a user manager) or with
`REFLECT_NO_SYSTEMD_RUN=1`, the spawn degrades to the old `setsid nohup` path
rather than losing the reflection. Either way `modes.<mode>.spawn_method`
(and `spawn_unit`) records which path ran.

`SIGKILL`, hard OS shutdown, and crashes remain out of scope for the worker
itself; the reaper below is what heals those.

### Orphan reaper

A mode stuck at `status:started` used to stay that way forever:
`is_already_complete` only ever *permitted a re-run*, and `SessionEnd` /
`SubagentStop` fire once per session. Detached workers therefore sweep after
their own terminal write, demoting any `started` older than
`REFLECT_STALE_STARTED_SECONDS` to a terminal `error` with
`reason: orphaned_started_reaped` plus the observed age. `find -mmin`
pre-filters candidates on manifest mtime and `REFLECT_REAP_MAX_PER_RUN` caps
the batch. It never runs on the synchronous precompact path.

### Mission artifact layout

```
tasks/mission.<sid>.md   payload, unique per session (never collides)
tasks/mission.md         symlink to the current payload
```

The payload name embeds the session id, so a machine write can never land on a
path a human owns. The pointer keeps `tasks/mission.md` — the path the
`SessionStart` reinject hook tests and the documented handoff convention —
working. The `<!-- written-against: sha=… ts=… sid=… -->` stamp no longer
protects the payload; it only decides whether the pointer may move:

| existing `tasks/mission.md` | action |
|---|---|
| absent | write payload, create pointer |
| symlink we own (incl. dangling) | write payload, repoint / repair |
| regular file, our stamp | preserve it under its own sid, then repoint |
| regular file, foreign or unstamped | payload only; leave it untouched, record the refusal |

`bash reflect.sh --mission-path <project-dir>` resolves the current payload
(pointer, else newest stamped payload by mtime) and logs how it resolved, so a
missing or dangling pointer never resolves silently. Payloads are
garbage-collected once `reflections/sessions/<sid>/` is gone or they exceed
`REFLECT_MISSION_RETENTION_DAYS`; the pointer target is always kept, and GC only
ever touches files that both match `mission.<valid-sid>.md` and carry our stamp.

Reflection is idempotent per-mode: reruns for the same `(session_id, mode)`
with `modes.<mode>.final_complete: true` exit fast without spawning a new
subprocess, unless `REFLECT_FORCE=1`. Different modes for the same session
never block each other — a PreCompact in flight does not stop SessionEnd
from producing `final.json`.

### Callers of `mission` mode

| caller | how | why that way |
|---|---|---|
| `reflect.sh precompact` (2nd+ compact) | `REFLECT_ASYNC=1` | the hook clock cannot afford a model call |
| `scripts/idle-handoff.sh` | synchronous | it reads `modes.mission.status` immediately after |
| `~/.claude/self-compact-trigger.py` (`Stop` hook) | `REFLECT_ASYNC=1 REFLECT_FORCE=1` | same hook-cap reason, and a threshold crossing must produce a handoff describing the state *at* the crossing — an earlier `complete` mission for the session would otherwise leave the resume working from something stale |

The self-compact trigger fires once per session per crossing of
`self_compact.threshold` (default 30% of the detected context window) and is OFF
unless `components.self_compact` is boolean `true` in
`~/.claude/recursive-self-improvement/config/config.json`. It only writes the
handoff and records a request; `scripts/idle-handoff.sh` performs the
reset+resume under its own guard chain. Nothing here auto-invokes `/compact` or
`/clear` — neither is agent-triggerable, and "reset" means the *next* process is
a fresh one seeded from the handoff.

## Inspecting artifacts

```bash
# List all sessions with reflection artifacts
ls -1 ~/.claude/reflections/sessions/

# See the manifest for a specific session
jq . ~/.claude/reflections/sessions/<sid>/manifest.json

# Read the final reflection
jq . ~/.claude/reflections/sessions/<sid>/final.json

# List checkpoint reflections for a long session
ls -1 ~/.claude/reflections/sessions/<sid>/checkpoints/

# Walk parent -> subagent tree
find ~/.claude/reflections/sessions/<parent-sid>/subagents -name final.json
```

## Pruning stale artifacts

Reflection artifacts are tiny (JSON, ~1-5 KB each). They accumulate one
directory per session id, which is fine for months of use. To prune:

```bash
# Delete artifacts older than 90 days
find ~/.claude/reflections/sessions -mindepth 1 -maxdepth 1 -type d \
  -mtime +90 -exec rm -rf {} +

# Delete worker logs older than 14 days
find ~/.claude/reflections/logs -type f -mtime +14 -delete

# Delete skipped-recursion markers older than 14 days
# In healthy operation this dir stays near-empty (the REFLECT_SUBPROCESS
# sentinel keeps recursion from firing at all — each marker is one
# observability record per skipped child hook). It still accumulates one
# small JSON per skipped fire over time; a periodic prune keeps it tidy.
find ~/.claude/reflections/skipped-recursions -type f -mtime +14 -delete
```

Do not automate deletion of `sessions/` until you have an aggregator
consuming those artifacts and know what "safe to delete" means for your
workflow. `logs/` and `skipped-recursions/` are pure observability records
with no downstream consumer and are safe to prune on a cron.

## Failure modes

- **Missing `session_id` or `transcript_path` in payload.** Writes an
  error record under `sessions/_malformed/` containing only the payload
  SHA-256 and length (no raw body) and exits 0. Never blocks the caller.
- **`session_id` fails safe-charset check (`^[A-Za-z0-9._-]{1,128}$`).**
  Same as above with `reason: "invalid_session_id"`. Rejects path
  traversal (`../evil`, `/abs/path`), spaces, newlines, control chars.
- **Concurrent invocation.** If a second dispatcher can't get the
  per-session `flock`, it records a `skipped_concurrent` marker under
  `<session_dir>/duplicates/` and exits fast without spawning a worker.
- **Duplicate after completion (per-mode).** If a session's manifest has
  `modes.<mode>.final_complete: true` for the invoked mode, a fresh
  invocation records a `skipped_duplicate` marker under
  `<session_dir>/duplicates/` and exits without touching the original
  manifest or artifacts. Other modes are unaffected — SessionEnd can still
  produce `final.json` even after PreCompact's mode is terminal-complete.
- **Stale `started` manifest (per-mode).** If `modes.<mode>.status`
  is `started` and `modes.<mode>.started_at` is older than
  `REFLECT_STALE_STARTED_SECONDS` (default 600s), the guard treats it as a
  crashed prior run for that mode and permits a fresh run.
- **`claude` subprocess exits non-zero.** Manifest status becomes
  `error` with `subprocess_exit_code`. Stderr in
  `logs/<sid>-<mode>.stderr.log`.
- **Timeout.** Manifest status becomes `timeout`. Compaction proceeds
  either way.
- **Model emits non-JSON.** Manifest status becomes `error` with
  `reason: "unparseable_reflection_json"`. Only the first 200 chars of
  the raw reply are preserved (as `raw_excerpt`); the full body is not
  written to the manifest to avoid leaking potentially sensitive
  reflection content.

## Security

- The reflection subprocess runs with `--tools ""`, disabling the entire
  built-in tool set. Even if a prompt-injection payload smuggled through
  the resumed transcript tries to make the model invoke `Bash`, `Edit`,
  `WebFetch`, etc., the CLI refuses. `--dangerously-skip-permissions`
  is NOT set.
- `session_id` and `parent_session_id` are validated against a safe
  charset before use in any filesystem path.
- The `--worker` re-entry mode requires `_REFLECT_INTERNAL=1` in env;
  external `reflect.sh --worker <mode>` invocations are refused.
- Artifacts are written with `umask 077` (owner-only permissions).

## Empirical basis

Verified 2026-08-08 against the shipped Claude Code build:

- `claude -p --resume <sid> --fork-session --output-format json` against
  a 12-minute-old sibling session returned
  `cache_read_input_tokens: 55,511` vs
  `cache_creation_input_tokens: 16,925` — roughly 77 % of input served
  from cache.
- Transcripts record `cache_creation` under
  `ephemeral_1h_input_tokens`; cache TTL is 1 hour, not the 5-minute
  default originally assumed.
- Transcript JSONL files persist raw tool result bodies (up to 38 KB
  per entry), so the prefix `--resume` replays is byte-identical to
  what the live session sent — prompt caching prefixes match.

See the source spec for details:
`~/.claude/proposals/manual/from 4th of august - rsi token efficiency.md`.
