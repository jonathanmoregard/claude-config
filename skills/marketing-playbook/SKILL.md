# Marketing Playbook (Marketing for Hippies method)

## Overview

Brand voice is not picked from options; it falls out of a point of view. Core method is
Tad Hargrave's "Marketing for Hippies": marketing's only honest agenda is **"is this a
fit?"** (attract, FILTER wrong-fit people out, lower risk) — never "close the deal".
Load-bearing line: *"If they don't buy your diagnosis, they won't buy your prescription."*

**Baseline failure this skill exists to prevent:** presenting polished brand-character
options (A/B/C personas with sample copy) before doing the POV work. Users reject these
as costumes. Voice = the founder's real voice carrying a belief they actually hold.

## When NOT to use

One-off posts/campaigns in an already-established voice → use brand-voice / content-engine.

## The protocol (in order, iteratively; ONE question per message)

1. **Voice profile** (REQUIRED SUB-SKILL: brand-voice) from the founder's real writing
   (blog, posts, emails). This is HOW the brand sounds; steps 2–5 supply WHAT it believes.
2. **Industry rant** — ask: *"What BS in this industry are you sick of? What broke your
   heart about it?"* Want beer-honest first-person heat, not design-doc language.
   Capture VERBATIM in the workbook; raw phrasing is copy raw-material.
3. **Island A → Island B** — the felt state before and after the product, in their
   words. A niche is a journey, not a demographic. Extract quotable assets.
4. **Diagnosis / Prognosis / Prescription** — draft from steps 2–3; becomes a
   founder-signed "Why X exists" philosophy page (Hargrave's "My Philosophy" deliverable).
5. **Niche as role in a community** ("the crew member who fixes logistics so the fun
   survives"), value alignment with that community, and hubs (people/venues that already
   have the audience's attention). Ask the user to rule on audience ordering.
6. **Message** — ~10 words, ideally verbatim-derived from their Island B. Score against:
   new idea / short / provocative / repeatable / simple / well-crafted / *them*.
7. **Voice guide + copy bank** — spectrums with X marks, humor rules (one wink per page
   on serious surfaces; jokes derived from THEIR humor register, never invented generic),
   lexicon, "phrases we'd never say". Then heroes, subheads, microcopy, ad concepts
   mapped to category entry points (the real-life "ugh" moments).

## Process rules (each learned from a real failure)

- **Workbook file from message 1**: verbatim quotes, dated decisions, LOCKED vs
  Later/TBD sections, standing copy rules. Context windows die; the workbook survives.
- **Approvals in small batches (~5), numbered**; accept terse verdicts ("1y 3n 8 rewrite").
- **Honest-claims rule**: no speed/effort claims that aren't measured; scope promises so
  they stay true under product change (a commitment page binds the founder forever).
- **User edits beat your drafts**: fold in silently, endorse what's genuinely good, push
  back only when an edit contradicts an earlier locked decision — and say which one.
- **Research before asserting**: marketing SOTA, competitor facts before any comparison
  copy, trademark + domain sweep before a name/rename sticks.
- **i18n early**: if the market is bilingual, every asset is a language PAIR approved
  separately; never auto-translate locked copy.

## Red flags — stop, you're doing it wrong

- Proposing brand characters, moodboards, or taglines before the rant + POV exist
- Presenting sample copy in a voice not derived from the founder's own writing
- Multiple questions in one message; interrogating instead of synthesizing between answers
- Humor that punches at users/readers, or jokes forced onto serious surfaces
